# 制作指示書：MV「羽衣」（16:9）

- ジャンル: AI歌手MV
- 尺: 271秒 / 縦横比: 16:9
- 目的: YouTube用のオリジナルMV。自社の音楽制作・AI動画制作の作例にもする
- コンセプト: 三保の松原の羽衣伝説×竹取物語。地上で恋をした天女が、羽衣をまとえば彼を忘れると知りながら月へ還る
- 色（3色）: 月・天：青白／銀／黒 / 地上の日々：夕焼けの橙／火の色 / 秘密が明かされた後：青黒／雨
- 音楽・SE: Suno「羽衣」H版（ダークな和楽器ポップロック・141BPM・ト短調・4分31秒）。歌詞はセリフ欄。SEは雨・波・風・三味線の余韻を編集で足す

## 制作の順番
1. 台本（秒割り） → 2. 原型画像 → 3. 動画化 → 4. 音楽・SE → 5. 編集
