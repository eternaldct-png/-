# ツヅリ — アイデアからショートアニメを作る（自分用）

アイデアを数行書くと、**脚本 → キャラ → 場面 → 絵コンテ → 絵と動き → 音 → 書き出し** の順に作り、
各段階で確認・手直ししてから 1本の mp4（字幕・声・BGMつき）に書き出す。代表の Mac で動かす。ログイン・支払いなし。
設計の記録は `replica/anime/`（recon.md / architecture.md / design/ / test-plan.md / bugs.md / build-log.md）。

## 使い方

1. `tools/anime_studio/start.command` をダブルクリック（初回だけ1〜2分かけて準備）。ブラウザで http://127.0.0.1:5056 が開く
2. 「＋ 新しく作る」→ アイデアを書く（`あまりん「今日こそ歌う！」` や `さな：がんばれ！` の行はそのキャラのセリフになる）→ 種類・絵柄・縦横・尺を選ぶ
3. 段階ごとに中身を見て、直すところは直接書き換えるか左の欄に指示を書いて「作り直す」。よければ「OK・次へ」
   - **キャラ**: 画像を入れる（LINEスタンプメーカーで背景を抜いたPNG・所属キャラの立ち絵など）→ 絵の段階でそのまま使う
   - **場面**: 背景の画像を入れる → その場面のカットの背景になる
   - **絵と動き**: 自分で描いた絵・ChatGPT で作った絵は「自分の絵にする」で1カットずつ差し替え（作り直しても残る）
   - **音**: BGM・曲を入れる。MV なら「カットの秒数を曲の長さに合わせる」
4. 「書き出す」→ プレーヤーで確認 →「ダウンロード」
5. よく出すキャラは「キャラ帳に保存」→ 次の作品で「キャラ帳から出演させる」

「おまかせ」にチェックを入れると、確認をとばして書き出しまで自動で進む。

### 便利な機能
- **決まりごと**: 作品ごと（ワークスペース左上「📌」）と、全部の作品共通（設定の「いつもの決まりごと」）。どの段階でも毎回AIに最優先で渡す
- **1カットだけ直す**: 絵コンテで「AIで直す」、絵と動きで「この絵だけ作り直す」。ほかのカットは変わらない
- **失敗したカットだけやり直す**: 1カット失敗しても他は進む。「絵が無い・失敗したカットだけ作る」で、そこだけ作り直す
- **続きを作る**: 書き出しの画面の「＋ 同じキャラで続きを作る」。キャラ（画像・声）・決まりごと・前の回のあらすじを引きつぐ
- **録った声に差し替え**: 音の段階で、読み上げが不自然なカットに自分（やライバー本人）の声を入れる
- **書き出す前の確認**: 絵が全部ある・セリフが収まる、などを自動で確認。BGMの権利・出演の了承は自分でチェック

## お金のかかり方（既定はすべて無料）

| 部分 | 既定（無料） | 任意（お金がかかる） |
| --- | --- | --- |
| 文章（脚本・絵コンテ） | AIなし（自分の文を並べる）／端末内AI Ollama | Claude API（`ANTHROPIC_API_KEY`） |
| 絵 | キャラ・場面の画像を合成した「仮の絵」＋自分の絵 | fal.ai の画像生成（`FAL_KEY`） |
| 動き | カメラの動き（寄り・引き・左右パン） | fal.ai の動画生成（`FAL_KEY`・高い） |
| 声 | Mac の読み上げ（say） | — |

- **Claude は「設定」で明示して選んだときだけ使う**（おまかせでは選ばない）
- fal.ai は月の上限（設定・見積もりベース）を超える前に止める。**モデル名と単価は fal.ai のモデルページで確かめてから設定に入れる**（既定値は仮）。fal.ai の管理画面側でも上限を設定しておくこと
- キーは `~/Tsuzuri/.env` に書く（リポジトリに入れない）:
  ```
  ANTHROPIC_API_KEY=...
  FAL_KEY=...
  ```

## 準備

- Python 3.10 以上（`python3 --version`。無ければ https://www.python.org/ から）
- 端末内AI を使うなら Ollama（https://ollama.com）を入れて、ターミナルで `ollama pull qwen2.5:7b`
- ffmpeg はいらない（`imageio-ffmpeg` に入っている。システムに ffmpeg があればそちらを使う）
- 声を増やすなら「システム設定 → アクセシビリティ → 読み上げコンテンツ」で日本語の声を追加

## データ

- `~/Tsuzuri/`（`tsuzuri.db` と `projects/<作品>/` の画像・音・動画、`library/` のキャラ帳）。フォルダごとコピーすればバックアップ
- `127.0.0.1` だけで待ち受ける（同じWi-Fiの他の端末からは開けない）。書き換えるAPIは独自ヘッダー `X-Tsuzuri: 1` 必須

## 著作権の注意

- 既存のアニメ・ゲームのキャラや曲を使わない（AIにも「オリジナルにする」と指示している）
- BGM は自作・フリー音源・Suno で作った曲など、使ってよいものだけ
- 所属ライバーのキャラ・声を使うときは本人の了承を取る
