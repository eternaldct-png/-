# オーディション申請Googleフォーム 質問項目案

ETERNAL d.c.t のライバー・配信者オーディション応募用に、Googleフォームへそのまま
コピーして使える質問項目案。Googleフォームの作成・公開はご自身のGoogleアカウントで
行ってください（forms.google.com → 空白のフォーム）。

---

## フォーム設定（フォームの「設定」タブ）

- タイトル: `ETERNAL d.c.t ライバー・配信者オーディション 応募フォーム`
- 説明文（例）:
  ```
  ETERNAL d.c.t では、一緒に活動してくれるライバー・配信者を募集しています。
  下記フォームに必要事項をご記入の上、送信してください。
  審査結果は応募いただいたメールアドレスへ後日ご連絡します。
  ※未成年の方は保護者の同意が必要です。
  ```
- 「メールアドレスを収集する」→ ON（連絡用に必須）
- 「回答を1回に制限する」→ ON推奨（Googleアカウントログインが必要になる点に注意。
  匿名で受け付けたい場合はOFFのままでOK）

---

## セクション1: 基本情報

| 項目 | 種類 | 必須 |
|---|---|---|
| お名前（本名） | 記述式（短文） | ✅ |
| ふりがな | 記述式（短文） | ✅ |
| 生年月日 | 日付 | ✅ |
| 年齢 | 記述式（短文・数値） | ✅ |
| 性別 | 選択式：男性 / 女性 / その他 / 回答しない | 任意 |
| メールアドレス | メールアドレス形式 | ✅ |
| 電話番号 | 記述式（短文） | ✅ |
| お住まいの都道府県 | プルダウン（都道府県） | ✅ |
| ご職業 | 選択式：学生 / 会社員 / フリーランス / その他 | ✅ |
| 未成年の方のみ：保護者の同意はありますか | 選択式：同意している / まだ得ていない / 該当しない（成人） | ✅ |

---

## セクション2: 活動について

| 項目 | 種類 | 必須 |
|---|---|---|
| 活動名（希望する名前があれば） | 記述式（短文） | 任意 |
| 配信・ライバー活動の経験 | 選択式：あり / なし | ✅ |
| 経験がある場合、活動歴・実績（プラットフォーム名／フォロワー数など） | 記述式（段落） | 任意 |
| 得意なジャンル・企画（複数選択可） | チェックボックス：雑談 / ゲーム実況 / 歌枠 / 料理 / ASMR / お絵描き / その他 | ✅ |
| 週にどのくらい配信・活動できますか | 選択式：週1回未満 / 週1〜2回 / 週3〜4回 / 週5回以上 | ✅ |
| SNSアカウント（X / Instagram / TikTok など） | 記述式（短文、複数行OK） | 任意 |

---

## セクション3: アピール・審査資料

| 項目 | 種類 | 必須 |
|---|---|---|
| 自己PR（400字程度） | 記述式（段落） | ✅ |
| 応募動機 | 記述式（段落） | ✅ |
| 過去の配信・動画URL（ポートフォリオ） | 記述式（段落、URL複数可） | 任意 |
| 顔写真 または 自己紹介動画 | ファイルアップロード | 任意 |
| 声のサンプル（音声ファイル or URL） | ファイルアップロード or 記述式 | 任意 |

※ファイルアップロード機能を使うには、Googleフォームの設定で
「ファイルアップロードを許可する」の同意（回答者にもGoogleログインが必要）が必要です。

---

## セクション4: 確認事項

| 項目 | 種類 | 必須 |
|---|---|---|
| 応募規約・プライバシーポリシーに同意しますか | チェックボックス：内容を確認し、同意します | ✅ |
| その他ご質問・ご要望 | 記述式（段落） | 任意 |

---

## 作成後の確認

- 「回答」タブ → スプレッドシートにリンク（右上の緑アイコン）しておくと、
  応募一覧をGoogleスプレッドシートで管理できます。
- フォームのURLを `eternaldct.net`（WordPress）や配信者募集告知の投稿からリンクしてください。
