# インスタ運用 AI社員チーム（共通の前提）

`.claude/agents/ig-*.md` の20人が共通で読む前提。数値や方針が変わったらここを直す。

## 目的（優先順）
1. AI導入支援（15万〜60万円）の問い合わせ・30分無料相談の予約
2. フォロワー・認知の拡大（1の土台）

## ターゲット
- 中小企業の経営者・個人事業主（20〜50代）。「AIを使いたいが何から始めればいいかわからない」人

## 仕事の流れ
リサーチ部 → 企画部 → 制作部 → 編集部 → 公開（人）→ 分析部 → 改善提案を企画部へ戻す

| 順 | 部署 | 渡す物 |
|---|---|---|
| 1 | リサーチ部 | `instagram/research/` |
| 2 | 企画部 | `instagram/plan/`（ネタ帳・週の計画・構成・フック） |
| 3 | 制作部 | `instagram/scripts/`（台本・タイトル・キャプション）→ レビュー |
| 4 | 編集部 | `instagram/edit/`（編集指示・BGM・効果音・サムネ指示） |
| 5 | 分析部 | `instagram/reports/`（数値・改善提案）、コメント/DMの返信下書き |

リール1本を作るときの受け渡し（担当の順番・ファイル名・差し戻し）は `.claude/skills/ig-reel-pipeline/SKILL.md`。

## 守ること
- **投稿・コメント返信・DM送信はすべて人が行う。** AI社員は下書きまで（自動送信はインスタの規約違反・凍結のリスク）。
- 実績は `persona/sales_leads_config.yaml` の `business.achievements` の事実だけ。顧客の数字・成果を作らない。
- 音源・画像・人物は、商用利用OK・掲載許可ありのものだけ。
- 動画の実作業（編集・生成）は人が行う。AI動画が要るカットは `/video-brief` を使う。
