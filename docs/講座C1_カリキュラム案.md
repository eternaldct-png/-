# AIショート動画 作品づくり講座（C-1）カリキュラム案

状態：叩き台（2026-11-28）。価格・ツール・規約は確認前の案。**販売前に弁護士の確認が必要**（特定商取引法・景品表示法・業務提供誘引販売取引）。

---

## 1. この講座で約束すること・しないこと

| 約束する（B地点） | 約束しない |
|---|---|
| AIと商用利用できるツールで、15〜30秒のショート動画を1本2時間以内に作れる | 収入・月〇万円・受注件数 |
| 作品5本（ポートフォリオ）がそろう | お仕事の紹介・あっせん |
| 料金表・制作の流れ・ヒアリングシートを持って、自分で営業できる準備がととのう | 「誰でも」「必ず」「1か月で」 |

**A地点（対象者）**：スマホで写真や動画を撮るくらいしかしたことがない、主婦・会社員・副業を始めたい20〜50代。パソコンかスマホがあり、週3時間ほど使える人。

**受講に向かない人（販売ページに書く）**：すぐに収入がほしい人／週3時間を取れない人／課題を出せない人。

## 2. 形式（案）

| 項目 | 案 |
|---|---|
| 期間 | 5週間（週1回×5回＋最終講評） |
| 授業 | Zoomのグループ授業 60分×5回（録画あり） |
| 質問 | Discordで受け付け、平日48時間以内に回答 |
| 定員 | 1期10人まで（社員2名で回せる上限として） |
| 価格 | 本番：3万〜5万円台（推測。試験運用の結果で決める）／試験運用：5人・1万円前後か無料 |
| 修了条件 | 作品5本を提出し、最終講評を受ける |

## 3. カリキュラム（全5回＋最終講評）

| 回 | テーマ | 授業でやること | 課題（作品） |
|---|---|---|---|
| 第1回 | 全体像と、使ってよい素材のルール | ショート動画の流れ（企画→台本→素材→編集→書き出し）。AIツールの商用利用・著作権・肖像権・BGMの権利。使うツールの登録 | **作品1：自己紹介動画（15秒）** |
| 第2回 | 台本とカット割り | 冒頭8秒の作り方（`instagram/台本の型.md` の型B）。1秒8文字のセリフ。`/video-brief` で秒割り台本を作る | 作品2の台本（告知動画） |
| 第3回 | 素材をAIで作る | 画像生成・動画生成（短いカット）・ナレーション。指示文（プロンプト）の書き方。素材の権利の確認方法 | **作品2：ライブ・イベントの告知動画（15〜30秒）** |
| 第4回 | 編集と書き出し | テロップのタイミング、3秒以上止まらない画、カット、音量。書き出し（1080×1920・30fps）。投稿前のチェックリスト | **作品3：商品・お店の紹介動画（30秒）** |
| 第5回 | 仕事として受ける準備 | ヒアリングシート、見積もり・料金表の作り方、制作の流れ、修正回数の決め方、契約で気をつけること（著作権の扱い・素材の権利） | **作品4：ビフォーアフター or 解説動画（30秒）**／**作品5：自由課題** |
| 最終講評 | 作品発表 | 1人ずつ講評。ポートフォリオ（作品5本＋料金表＋制作の流れ）を仕上げる | ポートフォリオ完成 |

- 作品の題材は、自分・家族・知人（本人の許可あり）か、講座が用意する架空の依頼にする。**実在する他人の商品・人物を無断で使わない。**
- 作品2（告知動画）は、ライバーの告知を想定した架空の依頼を用意する（事務所の強みを教材に生かす。実際の依頼ではない）。

## 4. 使うツール（候補・すべて要確認）

| 用途 | 候補 | 確認すること |
|---|---|---|
| 台本・指示書 | 自社の `/video-brief`、Claude などの生成AI | 受講生に開放するか（ログイン・費用・API料金） |
| 画像・動画生成 | Higgsfield など | 有料プランの必要性、商用利用の条件、生成物の権利 |
| 編集 | 商用利用が認められている編集ソフト | **CapCutは商用利用の条件に注意（台本集の指摘）。採用しない前提で比較する** |
| デザイン | Canva など | 無料・有料プランごとの商用利用の範囲 |
| BGM・効果音 | 商用利用可の素材サイト | クレジット表記の要否、SNSでの利用可否 |

→ ツールごとに「料金・商用利用・生成物の権利」を一覧にしてから確定する。

## 5. 販売ページで使う言葉・使わない言葉

| 使う | 使わない |
|---|---|
| 「5週間で作品5本」「1本2時間以内を目標に練習」 | 「月〇万円」「稼げる」「誰でも」「必ず」 |
| 「受注の準備（料金表・ヒアリングシート）まで」 | 「お仕事を紹介します」「卒業後は案件あり」 |
| 受講生の声（作品・かかった時間など事実のみ） | 収入の報告、平均的でない成果を代表例のように見せること |
| 定員10人（実際の定員） | 実際と違う「残りわずか」「予告なく終了」 |

**販売ページに必ず載せるもの（特定商取引法の通信販売の表示）**：事業者名・住所・電話・代表者、価格（税込）、支払い方法と時期、提供の時期、返品・解約の条件。内容は弁護士に確認する。

**販売の流れ**：販売ページ → 申込フォーム → 決済。**Zoomでの個別セールスはしない**（勧誘トラブルの形を避けるため）。質問はDiscordかLINEで文字で受ける。

## 6. 社内のお仕事との関係

- 講座の中で「事務所からお仕事を回す」と言わない・書かない（業務提供誘引販売取引に当たるおそれ）。
- 卒業生にライバーの動画を頼む場合は、講座の販売とは切り離し、別の業務委託契約で、作品と実力を見てから依頼する。進め方は弁護士に確認する。
