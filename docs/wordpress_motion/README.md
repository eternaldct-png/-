# eternaldct.net に「動画制作（モーション作例集）」ページを追加する手順

`https://kazuto-post-generator.onrender.com/motion`（作例集）を、ホームページ
`https://eternaldct.net`（WordPress・SWELL）の固定ページとして埋め込み、トップページに入口を置く。

WordPress はこのリポジトリの外で管理しているため、ここにあるファイルを **WordPress の管理画面に貼り付けて** 反映する。

## ファイル

| ファイル | 使う場所 | 中身 |
|---|---|---|
| `page_motion.html` | 新しい固定ページ「動画制作」 | 作例集の埋め込み（iframe）＋「全画面で作例を見る」リンク |
| `top_card.html` | トップページ | 「こんな動画、つくれます。」カード（クリックで `/motion/` へ） |
| `eyecatch.jpg` | 固定ページのアイキャッチ | 1200×630。SNSでシェアされたときの画像（OGP）にもなる |

`eyecatch.jpg` は `tools/motion_render/make_eyecatch.py` で作り直せる（作例のポスター画像から合成）。

---

## 手順1: 固定ページを作る

1. WordPress 管理画面 → **固定ページ → 新規追加**
2. タイトル: `動画制作`（「モーション動画 作例集」などでもよい）
3. ブロック追加（＋）→ **カスタムHTML** を選び、`page_motion.html` の中身をまるごと貼り付ける
4. 右サイドバー
   - **URL（パーマリンク／スラッグ）**: `motion` → `https://eternaldct.net/motion/` になる
   - **アイキャッチ画像**: `eyecatch.jpg` をアップロードして設定
   - （推奨）**SWELL設定でサイドバーを非表示**にすると、作例が横に広く表示される
     ※ SWELL のバージョンによって項目名が少し違う場合あり（確信度: 中）
5. **プレビュー**で作例が表示されることを確認 → **公開**

## 手順2: トップページに項目を追加する

トップページの作り方によって貼る場所が変わる。**設定 → 表示設定 →「ホームページの表示」** で確認する。

### A.「固定ページ」を選んでいる場合（トップを固定ページで作っている）
1. ホームページに指定している固定ページを編集
2. 入れたい位置（サービス紹介の並びなど）に **カスタムHTML** ブロックを追加し、`top_card.html` の中身を貼り付け
3. 更新

### B.「最新の投稿」を選んでいる場合（SWELL標準のトップ）
1. **外観 → ウィジェット** → 「トップページ上部」または「トップページ下部」エリア（SWELLのウィジェットエリア）
2. **カスタムHTML** ウィジェットを追加し、`top_card.html` の中身を貼り付け → 保存

### 別案: SWELL の「ピックアップバナー」を使う
トップ上部の画像バナー列に並べたい場合は、**外観 → メニュー** で新しいメニューに固定ページ「動画制作」を入れ、
表示位置を「ピックアップバナー」にする。バナー画像には固定ページのアイキャッチ（`eyecatch.jpg`）が使われる（確信度: 中）。

## 手順3（任意）: グローバルナビに追加

**外観 → メニュー** → ヘッダーのメニューに固定ページ「動画制作」を追加 → 保存。

## 注意点

- **`?preview=1` は付けていない。** `?preview=1` を付けると、ページ上部に
  「プレビュー表示中 —『制作中』の枠は…」という管理用の帯がお客さんにも見えてしまう。
  制作中の枠がない限り、表示される作例は `?preview=1` ありと同じ（現在は全15枠に動画あり）。
- **初回表示が遅いことがある。** Render の無料プランは15分アクセスがないとスリープし、
  次のアクセスで起動に約1分かかる。その間は「作例を読み込んでいます…」と表示される。
  トップのカードは画像を使わない（CSSだけ）なので、トップページの表示には影響しない。
- **Render の通信量。** 作例の動画は Render から配信される（全部見ると約12MB）。
  HPからのアクセスが大きく増えたら、Render の使用量を確認する。
- **「相談する」ボタンは出ていない。** `persona/motion_config.yaml` の `page.contact_url` が空のため。
  公式LINEの友だち追加URLを入れると、作例集の上部と下部に「制作について相談する」ボタンが出る。
- iframe が消える・表示されない場合は、WordPress のユーザー権限（管理者で編集しているか）や、
  セキュリティ系プラグインが iframe を削除していないかを確認する。
- 固定ページのスラッグを `motion` 以外にした場合は、`top_card.html` の `href` も合わせて変える。
