# X営業リスト（/leads）セットアップ手順

AI導入支援の見込み客を X で探し、DMを送り、返信にエージェントが自動で対応する仕組み。

```
Grokで探す → 候補を確認 → AIで下書き → 「Xで送る」を押す（文面入りDM画面が開く → 送信は人が押す）
        → 相手が返信 → エージェントが自動返信（10〜15分おき・営業時間のみ）
        → 契約/見積/苦情/「担当者」は自動で止めて LINE に通知 → 人が対応
```

## なぜ「最初のDMだけは人が送信ボタンを押す」のか

- X の自動化ルールは「頼まれていないメッセージを送ること」を禁止している（https://help.x.com/rules-and-policies/x-automation ）。
  知らない相手への最初のDMを API で自動送信すると、営業用アカウントが凍結されるおそれがある。
- 一方、**相手から来たDMに自動で返信すること**はルールで認められている使い方なので、返信はエージェントに任せる。
- 手動で送っていても、同じような文面を短時間に大量に送ると、スパム報告が重なって制限される。
  管理画面の「今日の送信 ○ / 目安 20件」を超えないようにする（目安は `daily_send_limit` で変更）。

## 1. 営業用 X アカウントを用意する

1. 本業とは別の営業用アカウントを作る（プロフィールに会社名・サービス内容・公式サイトを書く）。
2. 作ってすぐ大量に送らない。最初の1〜2週間は投稿やリプでアカウントを育てる。
3. DMの受信設定を「すべてのアカウントから受け付ける」にしておく（返信をもらいやすくする）。

## 2. 必要なキーを Render の Environment に設定する（kazuto-post-generator）

| 変数名 | 用途 | 取り方 |
|---|---|---|
| `XAI_API_KEY` | Grok で見込み客を探す | https://console.x.ai でAPIキーを作成 |
| `ANTHROPIC_API_KEY` | DM下書き・自動返信 | 設定済み |
| `LEADS_X_ACCESS_TOKEN` / `LEADS_X_ACCESS_SECRET` | 営業用アカウントとしてDMを読む・返信する | X Developer Console でアプリの権限を「Read and write and Direct message」にしてから、**営業用アカウントでログインした状態で** Access Token と Secret を発行する |
| `LEADS_X_API_KEY` / `LEADS_X_API_SECRET` | 上のアプリの API Key / Secret | 投稿用と同じアプリなら未設定でよい（`X_API_KEY` / `X_API_SECRET` を使う） |
| `LEADS_TASK_SECRET` | 自動返信の定期実行用の合言葉 | 適当な長い文字列 |
| `DATABASE_URL` | リストの保存 | 設定済み（未設定だと再デプロイでリストが消える） |

- X API は従量課金。DMの読み取り・送信は1回あたり約$0.01（1.5円前後）とする情報がある（第三者の解説記事。公式の料金表は Developer Console で確認すること）。
- 営業用アカウントの X キーが無くても、Grok検索・下書き・ワンクリック送信（文面コピー＋プロフィールを開く）は使える。自動返信には必須。

## 3. 自動返信を定期実行する

cron-job.org などで、次のURLを **10〜15分おき** に叩く（面談予約アプリのリマインドと同じやり方）。

```
https://kazuto-post-generator.onrender.com/tasks/leads-agent?token=<LEADS_TASK_SECRET>
```

- 初回は「今あるDMの位置」を記録するだけで、過去のDMには返信しない。
- `active_hours`（初期値 9〜21時）の外では返信しない。夜に来た返信は翌朝まとめて返す。
- 間隔を短くするほど X API の料金がかかる（1回の実行で最低1回はDMを読むため）。15分おき・9〜21時なら1日48回程度。

## 4. LINE 通知

返信・引き継ぎ・配信停止は、オーディション応募の通知と同じ「連携 admin」済みの LINE に届く（`docs/booking_line_setup.md`）。

## 5. 文面・エージェントのルールを変える

`persona/sales_leads_config.yaml` を編集してコミットするだけ（コード変更不要）。

- `business.achievements` に**事実だけ**を書く。ここに無い実績はAIに言わせない設定になっている。
- `agent.mode: "approve"` にすると、返信は自動送信せず「返信案」を作るだけになる（管理画面で確認して送る）。慣れるまではこちらが安全。
- `agent.handoff_keywords` / `stop_keywords` で、自動返信を止める言葉を調整できる。

## 法令・運用上の注意（専門家への確認を推奨）

- 集めたユーザー名・投稿・やり取りは個人情報にあたる可能性がある。目的外に使わない、不要になったら削除する。
- 「不要」「送らないで」と言われた相手には二度と送らない（自動で「配信停止」に入り、以後は送信されない）。
- 自動返信の1通目には「AIアシスタントが返信している」旨を表示している（`agent.disclosure`）。
