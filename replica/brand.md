**おすすめ: キキトメ。** 「聞いて、留めておく（外に出さない）」が切り口そのもので、同じ分野に同名が見当たらず、造語なので商標として残しやすい（推測）。
表記: カタカナ「キキトメ」、英字「Kikitome」。

これはふるい分けで、権利の調査ではない。**名前にお金をかける前（ドメイン取得・ロゴ発注・外販）に、弁理士に J-PlatPat での正式な調査を頼むこと。**
最低限、自分で J-PlatPat の「商標検索」で「キキトメ」「ききとめ」「KIKITOME」を、区分 9類（ソフトウェア）・42類（SaaS）で調べる。

## 3. ロゴの依頼文（デザイナー・画像生成AIへ）

- **考え方（1行）:** 朱の留め印（はんこ）の中に、音の波を1本の線で「留めた」形。聞いたことを、手元にしっかり留めておく。
- **形式:** シンボル＋文字（「キキトメ」のカタカナのワードマーク）。シンボル単体でもアプリアイコン・ファビコンとして使える。
- **色:** シンボルは朱 `#b5361c` の地に白。文字は `#1b1d24`。藍 `#2e3a87` はアプリ内のボタン色なので、ロゴには使わなくてよい。
- **大きさ:** 16px（ファビコン）でも波と留めの線が潰れないこと。1024px のアプリアイコンでも間延びしないこと。
- **納品物:** SVG（シンボル・横組み・縦組み）、アプリアイコン 1024×1024（iOS 用に透過なし）、ファビコン一式（16/32/180/512）、SNS用画像 1200×630。
- **避けること:** 円・輪・矢印が戻ってくる形（元のサービスを連想させる）。マイクのアイコンそのまま（ありふれている）。
  下書きは、元のサービスのロゴと並べて似ていないことを確認する。
- 仮のマーク: `tools/meeting_notes/static/mark.svg`（ファビコンと画面左上で使用中。正式なロゴができたら差し替える）。

## 4. 言葉づかい

**静か**（騒がない。ただし冷たくはしない）・**確か**（言い切れることだけ言う。ただし保証はしない）・**手短**（1文で済ませる。ただし大事な理由は省かない）

| する | しない |
| --- | --- |
| 「書き留めました」 | 「完了しました！🎉」 |
| 「録音はこのPCの外に出ません」と事実を言う | 「完全に安全」「100%プライバシー保護」と言い切る |
| 失敗したら、何が残っているか・次に何をすればいいかを言う（「録音は残っています。やり直す」） | 「エラーが発生しました」だけで終える |
| AIの結果には確かめる場所を添える（「数字と約束は文字起こしで確かめて」） | AIの結果を事実のように言う |
| 「あなた」と呼ばない。主語を省いて手短に | 「〜していただけますでしょうか」と長く丁寧すぎる |
