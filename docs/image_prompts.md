# 事業ビジュアルを image 2（GPT Image）/ Codex で生成する手順

`site/` の3枚の事業画像を、生成AI画像に差し替えるためのプロンプト集と取り込み手順。
（このリポジトリの Claude 環境からは OpenAI API に到達できないため、生成はあなたの Codex / ChatGPT で行う）

## 共通の指示（3枚とも先頭に付ける）

```
縦長 4:5 の画像。背景は純粋な黒（#050505）。全体はモノクロームで、
差し色はマゼンタ（#d94fe6）とシアン（#2fd6d8）の2色だけを全体の1割以下で使う。
写真のようなリアリズムではなく、暗室で光だけを記録した観測図のような静かな抽象表現。
文字・ロゴ・透かしは一切入れない。人物の顔は描かない。
高級ブランドのウェブサイトに置ける、余白の多い上品な仕上がり。
```

## 01 LIVE（ライバー事務所） → `biz-live`

```
暗いステージを上から差し込む3本の細いスポットライト（白・マゼンタ・シアン）。
客席のように同心の弧を描いて並ぶ無数の小さな光の粒。そのうち数個だけが大きく発光している。
下三分の一は暗い床の反射だけで、ほぼ黒。
```

## 02 AI（AI業務効率化） → `biz-ai`

```
黒地に規則正しく並ぶ微細なドットの格子。
その上を左から右へ流れる数本の細い光の経路が、格子の交点で折れ曲がりながら進む。
経路のうち2本はシアン、1本はマゼンタ、残りは白。中央の交点に一つだけ柔らかく光る核。
回路図と楽譜の中間のような、静かで知的な構図。
```

## 03 MUSIC（音楽制作） → `biz-music`

```
黒地に細い水平の線が数十本、等間隔に積み重なっている。
中央に近づくほど線が波形のように大きくうねり、端では平らになる。
1本だけマゼンタ、1本だけシアンの線が混ざる。
地層のような、音の記録のような静かな抽象。
```

## Codex で一括生成する場合の指示例

Codex（ChatGPT ログイン済み）のセッションで、このリポジトリを開いて以下を渡す:

```
docs/image_prompts.md のプロンプトで image 2 を使って3枚生成し、
generated/biz-live.png, generated/biz-ai.png, generated/biz-music.png に保存して。
```

※ Codex から画像生成ツールが使えるかはプランと時期で異なる（確信度: 低）。
使えない場合は ChatGPT の画像生成でプロンプトを1枚ずつ実行し、ダウンロードした画像を `generated/` に置く。

## 取り込み（4:5 に切り抜き → 1200×1500 → WebP → サイトに配置）

```bash
python3 scripts/import_biz_images.py generated/biz-live.png generated/biz-ai.png generated/biz-music.png
# → site/assets/img/biz-live.webp / biz-ai.webp / biz-music.webp を上書き（index.html の変更は不要）
git add site/assets/img/biz-*.webp && git commit -m "事業画像を生成AI画像に差し替え" && git push
```

ファイル名に `live` / `ai` / `music` が含まれていれば、どの順番で渡しても対応先を自動判定する。

## 生成画像を使う際の注意（事実と推測の区別）

- 生成画像の商用利用可否と権利は、利用しているサービスの規約で確認すること（OpenAI の場合は生成者に権利が帰属するのが原則だが、規約改定があり得るため要確認。専門家確認を推奨）。
- 実在の人物・ロゴ・他社サイトに似た構図が出た場合は採用しない。
- 現在の生成アート（`site/assets/art/make_art.py`）は権利上クリーンなので、差し替えは必須ではない。
