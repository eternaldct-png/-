# キキトメ — 録音を外に出さない会議ノート（自分専用）

会議を録音する（または録音ファイル・文字起こしを入れる）と、**要約・話題ごとのノート・担当者つきのやること**を書き留め、
あとからキーワード検索やAIへの質問で探せるアプリ。自分のPCだけで動く（設計の記録は `replica/`、ブランドは `replica/brand.md`）。
ログイン・支払いはなし。Render にはデプロイしない。フォルダ名・データの保存先（`tools/meeting_notes/`・`~/MeetingNotes/`）は
前の名前のまま（すでに使っているデータを動かさないため）。

**APIキー不要・端末保存だけで使える。** 録音・文字起こし・ノート・やることは、すべてこのPCの中で作り、このPCの中（`~/MeetingNotes/`）に保存する。
外部のAPIには何も送らない（Claude API は「設定」で自分から選んだときだけ使う）。

| ノートの作り方（「設定」で選ぶ） | 外に送るもの | 費用 | 質 | 必要なもの |
| --- | --- | --- | --- | --- |
| **自動（おすすめ・最初からこれ）** | なし | 無料 | 下の2つのどちらか | — |
| 端末内AI（Ollama） | なし | 無料 | 要約として書く。Claude より粗い（推測） | Ollama アプリとモデル（約5GB）。メモリ16GB以上のMac推奨 |
| AIなし（簡易まとめ） | なし | 無料 | 発言をそのまま抜き出すだけ（作り話は起きないが、要約ではない） | なし |
| Claude API | 文字起こしの文字 | 1時間の会議で数十円（推測） | いちばん高い | APIキー |

「自動」は、端末内AIが動いていれば端末内AI、無ければAIなしで書き留める。**APIキーがあっても Claude は自動では使わない。**

## 準備（最初の1回だけ）

1. **Python 3.10 以上**を入れる。ターミナルで `python3 --version` を実行して 3.10 以上ならそのままでよい。
   古い・無いときは https://www.python.org/downloads/ から入れる。
2. **起動する**。Finder で `tools/meeting_notes/start.command` をダブルクリック。
   初回は必要なものを自動でインストールするので数分かかる。終わるとブラウザで `http://127.0.0.1:5055` が開く。
   （「開発元を確認できない」と出たら、右クリック →「開く」）
   この時点で「AIなし（簡易まとめ）」で使える。

### 端末内AIを入れる（任意・おすすめ）

ノートを「要約」として書かせたいとき。入れたあとは何も設定しなくても「自動」で使われる。

1. https://ollama.com から Ollama（Mac 版）を入れて起動する（メニューバーにアイコンが出る）。
2. ターミナルでモデルをダウンロードする（約5GB・初回だけ）:

   ```bash
   ollama pull qwen2.5:7b
   ```

   メモリ8GBのMacなら、軽いモデルにして「設定」の「端末内AIのモデル名」も `qwen2.5:3b` に変える:

   ```bash
   ollama pull qwen2.5:3b
   ```

3. キキトメの「設定」→ 動作チェックで「端末内AI（Ollama）: 動いています」と出れば完了。

### 初回だけインターネットが要るもの

- 必要なもののインストール（start.command の初回）と、Whisper の文字起こしモデル（small で約500MB）・Ollama のモデルのダウンロード。
  **ダウンロードするだけで、録音や文字は送らない。** 一度入れたら、インターネットが無くても使える。

### Claude API を使いたいとき（任意）

「設定」で「Claude API」を選び、`~/MeetingNotes/.env` に `ANTHROPIC_API_KEY=sk-ant-...` を書いて起動し直す。
文字起こしの文字が Anthropic に送られ、費用がかかる（「設定」で月の上限を決められる）。

止めるときはターミナルの窓で `Ctrl + C`。

## 使い方

| やりたいこと | 操作 |
| --- | --- |
| 対面の会議を録る | ＋新しい会議 →「🎙 録音する」→ 録音を開始 → 停止 → 保存 |
| Zoom / Meet の相手の声も録る | 「オンライン会議の相手の声も一緒に録る」にチェック → 録音を開始 → 会議のタブを選び「タブの音声も共有」をオン（Chrome / Edge のみ） |
| 録音ファイルからノートを作る | 「📁 録音ファイルを入れる」で mp3 / m4a / mp4 などを選ぶ |
| Zoom / Meet の文字起こしからノートを作る | 「📄 文字起こしを入れる」で .vtt / .txt を選ぶ（話者の名前も取り込まれる。Whisper 不要で速い） |
| やることを片付ける | 上の「やること」→ 担当で絞ってチェック |
| 過去の会議を探す | 「会議」の検索ボックス。中身はAIの「AIに聞く」にも質問できる |
| Notion / Slack に貼る | 会議の画面の「コピー」（Markdown） |
| ノートの書き方を変える | 「設定」→ ノートの書き方の指示（例: 面談では配信経験・希望ジャンルを必ず項目にする） |
| 名前・専門用語の聞き間違いを減らす | 「設定」→ よく出る言葉・固有名詞 |
| 対面の面談を録る | 録音画面でマイク（外付け・スピーカーフォン）を選び、「会議室モード」をオン。声が小さい人がいるときは「設定」の「小さい声を拾うモード」も |
| スマホで録った録音を使う | スマホのボイスメモ → AirDrop でMacへ →「📁 録音ファイルを入れる」 |
| 話者を直す | 会議の「文字起こし」で名前を押して1行ずつ直す。参加者を入れておけば「🤖 話者をAIで推定」で空の行に推定の話者を付けられる |
| AI代を抑える | 「設定」→ AI費用の月の上限（超えたらその月はAIを呼ばない）。会議ごとの費用は会議の画面に出る |
| 録音を残す期間を決める | 「設定」→ 録音ファイルを残す日数（過ぎたら録音だけ消え、ノートは残る） |

**録音する前に、相手に録音することを伝える。** 無断録音は信頼を失うリスクがある（法的な扱いは状況で変わるので、
ライバー面談・商談で常用するなら専門家に確認しておく）。

## 費用の目安

- 自動・端末内AI・AIなし: **0円**（すべてPCの中で動く）。
- Claude API を選んだときだけ: ノート作成は1時間の会議1本でおよそ数十円、質問は1回数円〜（推測。会話量で変わる）。

## 音声の文字起こしの速さ

PC の CPU で動くので、会議の長さの数分の1〜同じくらいの時間がかかる（推測。PCによる）。遅いときは「設定」で
Whisper のモデルを `base` に、精度が足りないときは `medium` や `turbo` にする。処理中もアプリは使える。

## うまくいかないとき

まず「設定」の**動作チェック**を見る（✗ と ⚠ の行に直し方が出る）。

| 症状 | 対処 |
| --- | --- |
| 録音中にブラウザが落ちた・保存を押し忘れた | 録音は10秒ごとにPCへ保存されている。次に開いたとき一覧の「途中で止まった録音があります」→「会議として保存」 |
| やることに「⚠ 要確認」が付いた | AIが示した根拠の発言が文字起こしに見つからなかった。言っていないタスクかもしれないので、文字起こしで確かめて「確認した」か削除 |
| 「今月のAI費用が上限に達した」 | 「設定」で上限を上げるか、来月まで待つ |
| 上に「Claude API を選んでいますが、ANTHROPIC_API_KEY がありません」と出る | 「設定」でノートの作り方を「自動」か「端末内AI」「AIなし」に戻す |
| 「端末内AI（Ollama）につながりません」で失敗した | Ollama のアプリを起動してから、会議の画面で「やり直す」 |
| 「モデル … がまだありません」 | ターミナルで `ollama pull qwen2.5:7b`（「設定」のモデル名と同じもの） |
| ノートが発言の抜き出しになっている | 「AIなし」で作られた。端末内AIを入れてから「ノートを作り直す」 |
| 録音が「失敗」になり faster-whisper が必要と出る | ターミナルで `tools/meeting_notes/.venv/bin/pip install faster-whisper` → 起動し直す → 会議の画面で「やり直す」（録音は消えていない） |
| 「モデルを読み込めませんでした」 | 初回のモデルのダウンロードに失敗している。ネットにつながる状態で「やり直す」 |
| マイクが使えない | ブラウザのアドレスバー左の鍵マーク → マイクを「許可」。Mac の「システム設定 → プライバシー → マイク」でブラウザを許可 |
| 相手の声が入っていない | 「タブの音声も共有」をオンにし忘れている。Zoom のデスクトップアプリの音はタブ共有では録れないので、ブラウザ版の Zoom を使うか、Zoom の録画（m4a）を「録音ファイルを入れる」から取り込む |

## データ

- 置き場所: `~/MeetingNotes/`（`meeting_notes.db` と `audio/`）。フォルダごとコピーすればバックアップになる。「設定」から JSON でも書き出せる。
- 別の場所に置きたいときは、起動するときに `--data /path/to/dir` を付ける（`run.py`）。
- アプリは `127.0.0.1` でだけ待ち受けるので、同じ Wi-Fi の他の端末からは開けない。

## 開発者向け

```bash
python3 tools/meeting_notes/run.py --port 5055 --data /tmp/mn-dev
```

