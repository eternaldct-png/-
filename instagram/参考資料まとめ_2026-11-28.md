## 1. 長編リールの型（「インスタ集客は絶対にバズらせたらいけません」）

流れ（長めのトークリール）
1. 極論のタイトル
2. 自己紹介と実績（短く）
3. よく言われるノウハウを並べる（「〜ってよく言われますよね？」）
4. 「その結果どうですか？」と現状を突きつける
5. 見ている人の心の声を長めに代弁する（不安・焦り・自己嫌悪まで）
6. 「結論、さっきのノウハウは全部間違い」とひっくり返す
7. 見ている人の反論を先に言う（「でもこう思いますよね？」）→ なぜ古い情報が広まるのかを説明
8. 本編：フェーズ1「カテゴライズ（何の専門家かをはっきりさせる）」、フェーズ2「投稿の評価の積み上げ（まず既存フォロワーに評価してもらう）」
9. 次の段階（商品設計・動線設計・インサイト）は固定投稿へ誘導
10. 締め：「見返して、コメントでアウトプットして。質問に答えます」

## 2. リアルタイムリサーチの効率化（Google検索でリールを探す）

- Googleの検索窓に `site:www.instagram.com/reel/ キーワード after:YYYY-MM-DD` と入れる（日付は1週間前）。
- 検索結果で評価（いいね）が多いものを開き、プロフィールのフォロワー数と再生回数を比べる。**フォロワー数より再生回数が多いもの**だけをリサーチ対象にする。
- Googleに登録（インデックス）されたリールしか出ない、という注意書きあり。

## 3. Museで使えるプロンプト（AIに渡す指示文の集まり）

| プロンプト | 中身 |
|---|---|
| セキュリティ設定 | AIにブラウザでログイン・クリック・送信をさせない、定期タスクにもその一文を入れる、というルール |
| 冒頭フック生成 | 元リールを「肯定」するか「否定」するかを最初に選ばせ、30案から10案を出す。15〜30文字・2〜5秒・何の話か分かる・断定する |
| リアルタイム競合リサーチ | 過去7日・3万回以上・再生回数がフォロワー数以上、のリールURLを最大50件集める |
| リンク出力リサーチ | 過去1か月・いいね200以上のリールURLを最大30件集める |
| 台本制作 | 冒頭フック（0〜3秒）→ 努力の否定＋結論（3〜15秒）→ 解説（15〜60秒）→ 警告で締め（60〜75秒）。コメント誘導は禁止 |
| 台本制作（強烈なフック版） | URLを渡すだけで分析〜台本まで。フック7型（常識破壊・努力全否定・原因暴露・業界批判・敵味方分断・残酷な現実・逆説） |
| リサーチ＋台本10本一括 | 上の2つをつなげ、1リンク1台本で10本作る。CSVでも保存 |
| 改善プロンプト | 既存リールを8項目×5点で診断 → フック9案 → 改善 |

**このアカウントで使うときの注意**
- フック系プロンプトは「炎上リスク許容・超攻撃型」が前提になっている。CLAUDE.md の絶対ルール（炎上ネタ・人の悪口・根拠のない数字は禁止）とぶつかるので、使うなら「攻撃的に」の部分を外して使う。
- 「他人のリールの再生数は正規の方法では取れない」とプロンプト自身が書いている。リサーチ系は、AIが存在しないURLや数字を作ってしまう危険がある。出てきたURLは必ず人が開いて確かめる。

## 4. LINE配信用長尺台本（約7万字のセールス動画の台本）

**全体の流れ（約1時間の動画を想定）**
1. 自己紹介 → 無料プレゼント10個の一覧
2. 実績の羅列（フォロワー数・売上・店舗数など）
3. 「この動画・資料・ウェビナーの3段階で学ぶ」と説明。エントリー手順を2回くり返す
4. 「巷のノウハウに疲れていませんか」→ 見ている人の悩みを大量に代弁
5. 「原因はフォロワー数やバズを追うという勘違い」と言い切る
6. 失敗事例（フォロワーが多いのに売れない人）
7. 受講生の実績紹介
8. **本編：6ステップ**
9. ウェビナー（有料・特別価格）への申し込みを何度も促す。「予告なく終了」「定員あり」で締め切りを強調

**本編の6ステップ（要点）**

**① リサーチ**
- 自分のジャンルで1年〜1年半以内に伸びたリールを50〜100本保存する。
- 再生回数がフォロワー数より多いものだけ対象（フォロワー5万で1万回再生は対象外、フォロワー1000で1万回再生は対象）。
- 目的は真似ではなく「需要（ニーズ）を知ること」。例：「信頼できる店か知りたい」という不安から「当たりのサロンを見分ける方法」がヒットした。

**② コンセプト設計**
- 保存したリールの「テーマ・構成・冒頭8秒」の3つを書き出す。余裕があれば「尺」と「自分から見て間違っている・足りないところ」も。
- 伸びているリールには、1分では伝えきれない「足りない情報」が必ずある。そこを補う・反論する形で発信する。
- 対象者の今いる地点（A）と行きたい地点（B）を、妄想ではなくリサーチから決める。AからBに必要な情報がコンセプト。

**③ タイトル・台本**
- スピード重視。1つのニーズからタイトルを複数パターン作る。資料で確認できたのは「① 極論（言い過ぎだろ、くらいの言い切り）」「② 逆張り（よく言われていることの逆。伸びている投稿の足りない部分を突く）」の2つ（3つ目は資料内に見当たらず、ウェビナーで話すとしている）。
- 作者自身、極論は「選んでもらうための言い方で、事実ではない」と書いている（例：「ストーリーズを1日3枚上げてもアカウントは潰れない」）。
- 台本は1本1テーマ。タイトルの次に必ず「導入」を入れる。導入は次の3つのどれか：
  1. 見ている人が内に秘めている気持ちを代弁する
  2. やりがちな行動を言葉にする
  3. 解決しないと起きる最悪の未来を言葉にする
- 対象者の悩みは大きくは変わらないので、一度つかめば導入は書きやすくなる。30本くらいで形になる、としている。

**④ ジャンル設定**
- 同じテーマの投稿を続けると、最短30〜50投稿で全体のリーチが上がり出す（作者の別アカウントでは100投稿かかった）。
- 進み具合の確認：フォローしてくる人が想定どおりの人か目で見る／別アカウントから自分のプロフィールを開き、「おすすめ」に同じジャンルの人が出るか見る。
- 自分からやること4つ：①最初の30投稿までは同じジャンルで2週間以内に更新がある人だけフォロー ②いいね・コメントは1日10回以内 ③同ジャンルの人のストーリーズに反応してDMでやりとり ④リール・ストーリーズ・Threadsまで全部同じジャンルに絞る。

**⑤ エンゲージメントの担保**
- 目的は「リーチの整合性」（興味がある人に届き続けること）。
- ストーリーズの閲覧率をフォロワー1万人以下は30％、1万人以上は20％に保つ、としている（作者と受講生の実績から出した基準。公式の数字ではない）。
- 理由：ストーリーズをよく見る人には新しいリールが先に表示される → 最初の反応が興味の近い人に揃う → その後、似た人に広がる。

**⑥ マネタイズ戦略**
- インスタのお金の作り方は大きく3つ：アフィリエイト・PR案件／自社の講座・情報販売（代理販売・運用代行を含む）／実店舗への集客。
- 結論は「全員、自社のオンライン講座を持つべき」。原価がかからず利益率が高い、としている。
- アフィリエイトは、①収入の出どころを他社に握られる ②ステマ規制などの規制 ③お客さんの名簿が残らない、の3つで本業には危険、としている。運用代行も初心者にはすすめない。
- 講座づくりは「AB設定」：誰を（A地点）どこまで（B地点）連れて行くかで、必要な実力が決まる。例として、高齢者向けのスマホ・パソコン講座が挙がっている。
- 試算の例：講座30万〜100万円×5〜10人＝150万〜1000万円。フォロワー数は関係ない、としている（作者の試算。保証ではない）。

## 5. ローンチ前のストーリーズ

- 1か月前に1回だけ告知する
- 3週間前から週2〜5回ライブ（日程と内容を決めて告知）
- オプトイン（LINE登録など）開始の3日前から前振り
- ウェビナーの10日前にオプトイン開始。当日もライブ
- リールは1か月前から毎日更新
- 日時に集中させる／販売があることも伝える

## 6. このアカウントに取り入れるなら（提案）

| 取り入れるもの | 使い道 |
|---|---|
| リサーチの基準「再生回数＞フォロワー数」とGoogle検索のやり方 | 週次ルーティンの企画づくり（歌配信・AI活用のネタ探し） |
| 「伸びているリールの足りない情報を補う」 | 企画の切り口づくり |
| A地点→B地点のコンセプト設計 | ライバー募集（例：A＝趣味で歌っている主婦、B＝配信で応援される人）と、AI導入支援（A＝手作業で残業している中小企業、B＝定型業務をAIに任せている会社）の2本立て |
| ローンチ前ストーリーズの日程 | オーディション募集・AI導入の無料相談会の告知 |
| タイトルの次の「導入」3パターン | `instagram/台本の型.md` の冒頭8秒の作り方と同じ。週次ルーティンの台本づくりで使う |
| ジャンル設定のための自分からのアクション | 歌配信・ライバー系とAI活用系が混ざっていて、ジャンルがぶれている可能性がある（推測）。どちらを主にするか決める必要あり |
| AB設定の講座づくり | 既存の商品（AI導入支援 15万〜60万円、ライバー育成）を「A地点→B地点」で言い直すと、リールのテーマとそのままつながる |

**取り入れないもの**
- 攻撃的なフック・業界批判（CLAUDE.md の絶対ルールに反する）
- 「予告なく終了」「定員」で急かす売り方。実際に終わらせないのに書くと景品表示法の「有利誤認」に当たるおそれがある。使うときは弁護士・専門家に確認する。
- 根拠の確認できない実績・数字の書き方
