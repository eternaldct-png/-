# リール台本の型（CTAまでの流れ）

参考にしたもの：本人が共有した、インスタ運用ノウハウ系アカウントの台本集（2026-11-28。1回目100本、2回目411本＋作者の構成メモ）。
**中身・言い回しは写さない。抜き出したのは「流れの型」だけ。** 台本番号は2回目の台本集（411本）の番号。
**口調は標準語。大阪弁（関西弁）は使わない**（本人の指示 2026-11-28）。

---

## 1. 流れの型（3つ）

### 型A：基本（問題提起型）
作者が「基本の構成要素」として挙げている流れ。

| 順番 | 部品 | 書くこと |
|---|---|---|
| ① | タイトル＆問題提起 | 「誰の・何の問題か」を1文で言い切る |
| ② | 問題の深掘りと煽り | そのままだとどうなるか（放っておいた先の困りごと） |
| ③ | インサイトの深掘り | 表に出ている悩みの裏にある、本当の気持ち |
| ④ | 本編 | 解決策（手順は3つまで）→ まとめ |

元の台本：32・87・100・130（タイトル → 問題提起 → 問題の拡張 → 内容）。

### 型B：コールドリーディング型（作者が「最近かなり使える」としている流れ）

| 順番 | 部品 | 書くこと |
|---|---|---|
| ① | 冒頭 | 極論で言い切る1文 |
| ② | コールドリーディング | 見ている人の気持ち・やりがちな行動を言い当てる（「〜していますよね」） |
| ③ | 答えを言わない結論 | 「ポイントは〇〇にあります」と方向だけ見せ、中身はまだ言わない |
| ④ | 内容への興味付け＆成果の期待 | 「これが分かると〜できるようになります」 |
| ⑤ | 内容＆まとめ | 解決策 → 一言でまとめる |

元の台本：211・222・230・344・345。230は「このリールもこの構成で話しています」と、構成そのものをネタにしている。

### 型C：たとえ話型

| 順番 | 部品 |
|---|---|
| ① | タイトル（問題提起） |
| ② | たとえ話（身近な場面で本題を言う） |
| ③ | 問題提起と問題の拡大 |
| ④ | 内容 |

元の台本：222（3つ目の構成として挙げている）、83・89・145。

## 2. 冒頭8秒の作り方（いちばん大事）

作者は「冒頭3秒ではなく8秒が大事」「0.5秒・3秒・8秒にそれぞれ壁がある」としている（289・306・307・368）。

| 秒 | やること | このアカウントでの注意 |
|---|---|---|
| 0〜0.5秒 | 間を空けずに話し始め、同時にテロップを出す。何のジャンルか一目で分かる画にする | 冒頭に表紙画像を1秒挟まない（349）。無音を0.1秒も入れない |
| 〜3秒 | 極論のタイトル。次の4つのどれかを入れる | 下の「4つの要素」を見る |
| 〜8秒 | 気持ち・行動の代弁 → 否定、または「放っておくとこうなる」→ 内容への興味付け | セリフは1秒8文字以内なので、8秒で約64文字まで |

**タイトルに入れる4つの要素**（23・34・87）
1. 常識の否定：「〇〇は、実は逆です」
2. すぐ得をする話：「これだけで〇〇が変わります」（効果の数字は入れない）
3. やってはいけないこと：「〇〇すると損をします」（作者は「やった方がいいこと」より「やってはいけないこと」の方が刺さるとしている）
4. 感情：驚き・悔しさ・うれしさをそのまま出す

**2文目に「見ている人の気持ち」を1つ入れる**（385のあとの台本）
- 例：「また大げさな、と思いましたよね。」「台本を書いた方がいいと聞いて、自分なりに書いてみたけど、どこかやりにくい。」

**対象者は「〇〇な人必見」ではなく、行動と気持ちで絞る**（338・137）
- だめ：「歌配信が伸びない人必見」
- よい：「配信のたびに選曲を変えているのに、来てくれるのは毎回同じ3人で、終わったあと少し落ち込んでいる人」

**避ける2つの冒頭**（147）
- 「でしょうね」型：誰でも知っている結論を先に言う（「配信は継続が大事です」）
- 「結論が見えなさすぎ」型：何の話か分からない煽り（「これやると終わります」だけ）

## 3. インサイト（本当の悩み）の掘り方

| 手順 | やること | 元の台本 |
|---|---|---|
| 1 | DM・コメント・面談で聞いた「表の悩み」を書き出す | 9・359 |
| 2 | その裏の気持ちを書く（例：「フォロワーが増えない」の裏は「売上が上がらず焦っている」） | 6・9 |
| 3 | 対象者の5つを書く：①誰が必要としているか ②今と過去 ③なりたい未来 ④裏にある不安 ⑤すでに試したこと | 337 |

## 4. CTA（締め方）の型

作者は「CTAは基本いらない」「毎回のコメント誘導はやめる」と言いつつ（51・70・148・216）、実際には次のような軽い締め方を使っている。

| 型 | 言い方 | 狙い | 元の台本 |
|---|---|---|---|
| ① 回遊 | 「やり方はこのアカウントで全部話しています」 | 他の投稿も見てもらう | 33・73・157 |
| ② 続きはフォロー | 「続きは次のリールで。フォローして待っていてください」 | フォロー | 161・165 |
| ③ 固定投稿へ | 「固定の投稿で詳しくまとめています」 | 回遊 | 14・101・358 |
| ④ 質問を受ける | 「分からないところはコメントで質問してください」 | 会話・エンゲージ | 32・50 |
| ⑤ 今すぐ行動 | 「保存して終わりにせず、今日1本書いてみてください」 | 実行（保存より行動を頼む） | 222・326・338・368 |
| ⑥ 言い切って終わる | CTAなしで主張を言い切る | 印象を残す | 10・61・94 |

- 作者は「保存してね」と頼むCTAは意味がないとしている（84）。理由は「保存が増えたから伸びるわけではない」というもの（作者の意見。裏付けは未確認）。
- このアカウントの「配信の相談は、プロフィールのリンクから」は毎回入れず、週に数本に絞ることを提案（推測：毎回の案内は「売り込み」と受け取られやすい、と作者は繰り返し言っている）。

## 5. このアカウントで使うときの決まり

### 5-1. 大阪弁は使わない（標準語に直す）
| 元の言い方（大阪弁） | 標準語にすると |
|---|---|
| 〜やん／〜やろ？ | 〜ですよね／〜ですよね？ |
| あかん | だめです／もったいないです |
| 〜してへん／〜でけへん | 〜していない／〜できない |
| ほんで | それで |
| ゆーてる | 言っている |
| 知らんけど | （入れない） |
| 誰がみんねん | それは見てもらえません |
| 〜ちゃう？ | 〜ではありませんか？ |

### 5-2. 元の台本から使わないもの（CLAUDE.md の絶対ルール）
| 元の台本でよく出るもの | このアカウントでの扱い |
|---|---|
| 「アホ」「情弱」「ゴミ」「キモい」など見ている人を下げる言葉 | 使わない。「もったいないです」「損をしています」に変える |
| 「詐欺師」「ゴミコンサル」など同業を下げる | 使わない。下げる相手は**人ではなく古い思い込み**（共通の敵）。他の事務所への批判は名誉毀損の心配もあるので、気になるときは弁護士に確認 |
| 「15億人」「2億倍」「リーチ10倍」などの大げさな数字・出典のない数字 | 使わない。冗談の数字も入れない。数字は自社インサイトの実数か `business.achievements` の事実だけ |
| 「4億」「4万フォロワー」などの実績 | 自社の事実に置き換える。無ければ実績の部分ごと抜く |
| 開示請求・アンチへの反撃 | 使わない（炎上NG） |

**共通の敵（人ではなく思い込み）**
| ジャンル | 共通の敵 |
|---|---|
| 歌配信・ライバー | 「長く配信すれば伸びる」「歌がうまければ人は来る」「毎日やらないとだめ」 |
| AI業務効率化 | 「AIは難しい・高い」「全部AIに任せれば楽になる」「うちの規模には関係ない」 |

### 5-3. 読み上げ（本人のクローン音声）
- CLAUDE.md の「🎙 リールの読み上げ文のコツ」に従う（数字・読み間違えやすい語はひらがな、読点は意味の切れ目だけ）。
- コールドリーディングの文は長くなりやすい。1秒8文字を超えないよう、文字数はコードで数える。
- 今のリールは18秒前後。型Bは冒頭8秒で全体の半分近くを使うので、**25〜35秒**を目安にする（作者は短い動画は届きやすく、長い動画は集客に効く、と使い分けている：37・93・184）。

## 6. このアカウント用テンプレート

### テンプレート1：型B（狙い：最後まで見られる・フォロー）
| 部品 | 書くこと |
|---|---|
| ① 冒頭 | 「〈相手の悩み〉、原因は〈思い込み〉ではありません。」 |
| ② コールドリーディング | 「〈やりがちな行動〉を試していますよね。それでも〈困っていること〉。」 |
| ③ 答えを言わない結論 | 「見直すのは、〈場面〉のひとつだけです。」 |
| ④ 興味付け＆期待 | 「ここを変えると、〈なりたい状態〉に近づきます。」 |
| ⑤ 内容＆まとめ | 解決策（3つまで）→ 一言まとめ → CTA（回遊 or フォロー） |

例（歌配信）
- ①「歌配信で毎回同じ人しか来ないなら、原因は歌ではありません。」
- ②「選曲を変えたり、配信時間を延ばしたり、いろいろ試していますよね。それでも初見さんが残らない。」
- ③「見直すのは、配信の最初の1分だけです。」
- ④「ここを変えると、初見さんが最後までいてくれる理由ができます。」
- ⑤ 最初の1分でやること3つ → 「他の配信のコツも、このアカウントにまとめています。」

例（AI業務効率化）
- ①「AIに頼んだ文章を、結局ぜんぶ書き直していませんか。」
- ②「便利だと聞いて使ってみたけど、敬語が変で、うちの会社らしくない。結局手で直して、かえって時間がかかる。」
- ③「原因は、頼むときの最初の一行です。」
- ④「この一行を変えると、直す手間がぐっと減ります。」
- ⑤ 最初の一行に入れる3つ（相手・目的・文字数）→ 「保存で終わらせず、今日のメールで1回試してください。」

### テンプレート2：型A（狙い：保存）
| 部品 | 書くこと |
|---|---|
| ① タイトル＆問題提起 | 「〈場面〉で〈やりがちなこと〉をすると、損をします。」 |
| ② 深掘り | 「続けると〈困ること〉になります。」 |
| ③ インサイト | 「本当は〈裏の気持ち〉なのに、〈表の行動〉で埋めようとしているからです。」 |
| ④ 本編 | 「かわりに〈やること〉を3つ。」→ まとめ |

### テンプレート3：型C（狙い：シェア）
| 部品 | 書くこと |
|---|---|
| ① タイトル | 「〈思い込み〉は、〈たとえ〉と同じです。」 |
| ② たとえ話 | 身近な場面（料理・運転・待ち合わせなど） |
| ③ 問題提起と拡大 | 「〈ジャンル〉でも同じことが起きています。」 |
| ④ 内容 | 解決策 → 「同じことで悩んでいる人に送ってあげてください。」 |

## 8. 書いたあとのチェック
- [ ] 0.5秒で話し始め、最初の1文で「誰の・何の話か」が分かるか
- [ ] 2文目に見ている人の気持ち・行動が入っているか
- [ ] 8秒以内に「方向は見えるが中身はまだ」という状態になっているか
- [ ] CTAは1つだけか（回遊・フォロー・質問・今すぐ行動・相談のどれか）
- [ ] 大阪弁・人を下げる言葉・出典のない数字・大げさな数字が入っていないか
- [ ] セリフが1秒8文字以内か（コードで数える）
