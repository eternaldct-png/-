# 公式LINE配信文（ETERNAL版 email-campaigns）

1回の配信で、読んだ人に**1つの行動**（応募・予約・購入・配信を見に来る）をしてもらう文章を作る。
**下書きまで。配信（送信ボタン）は人が LINE Official Account Manager で押す。**

## 0. 先に決めること
| 項目 | 例 |
|---|---|
| 誰に | 応募検討者／所属ライバー／リスナー／グッズ購入者／AI導入の見込み客 |
| ねらう行動（1つ） | `/audition` で応募、`/book/kazuto` で相談予約、`/goods` で購入、今夜の配信に来る |
| 配信日時 | 曜日・時間（下の目安） |
| 使える通数 | 今月の残り通数（下の「通数の計算」） |

対象が混ざる場合は**分けて別の配信**にする（AI導入の案内をライバー全員に送らない）。

## 1. 通数の計算（毎回やる）
- 公式LINEは「メッセージ1通 × 送る人数」で通数を使う。1回の配信の吹き出しは最大3つで、3つでも1通。
- 料金プランの目安（2026年11月時点の民間解説サイト情報。**最新は LINE Official Account Manager の料金ページで確認**）:

| プラン | 月額（税別） | 無料メッセージ |
|---|---|---|
| コミュニケーション | 0円 | 200通 |
| ライト | 5,000円 | 5,000通 |
| スタンダード | 15,000円 | 30,000通（超過分は従量） |

- 友だち数×配信回数が上限を超えるなら、配信回数を減らすか、セグメント配信に絞る。**計算はコードで出す**。
- 面談予約アプリの通知（Messaging API）は別の公式アカウントなら別枠。同じアカウントならこの通数を食う。

## 2. 文章の型
LINEはトーク一覧と通知で**最初の1行（20文字前後）**しか見えない。メールの件名＋プレビュー文の役割をここで果たす。

```
吹き出し1（必須）: 1行目に「誰向け・何の話か」＋ 本文3〜5行 ＋ 行動のURL
吹き出し2（任意）: 画像 or リッチメッセージ（タップ先は吹き出し1と同じURL）
吹き出し3（任意）: 補足（締切・よくある質問1つ）
```

- 1行目の例：「【歌が好きな方へ】ライバー募集、今月末まで」「chacoのTシャツ、今日から販売です」
- 本文は**スマホで3スクロール以内**。1文は短く、改行で区切る。
- URLは1つ。ボタン（リッチメッセージ・カードタイプ）を使う場合も行き先は同じにする。
- 絵文字は1吹き出しに1〜2個まで。
- 締切・日時は曜日つき（「11/30（日）23:59まで」）。

## 3. 目的別の型
| 目的 | 1行目 | 中身の順番 |
|---|---|---|
| オーディション募集 | 【歌が好きな方へ】〜 | 不安を1つ消す（顔出し不要など事実のみ）→ 締切 → 応募URL |
| ライバー向けお知らせ | 【所属ライバーのみなさんへ】〜 | 何が変わるか → いつから → やること（あれば）→ 質問先 |
| イベント・配信告知 | 今夜21時〜 ○○ | 見どころ1つ → 時間 → 枠のURL |
| グッズ発売 | ○○、今日から販売 | 写真 → 価格（税込・送料込み）→ 購入URL |
| AI導入の無料相談 | 【経営者・個人事業主の方へ】〜 | よくある悩み1つ → 30分でやること → 予約URL |

## 4. あいさつメッセージ・ステップ配信
- **あいさつ**（友だち追加直後）：お礼 → このアカウントで届くもの（頻度も）→ 最初の1つの行動。長くしない。
- **ステップ配信**（追加後の日数で自動送信）：0日目あいさつ → 2日目 よくある質問 → 5日目 実例（事実だけ）→ 7日目 行動の案内。
  各通で通数を使うので、**友だち追加数×ステップ数**で月の通数を見積もる。

## 5. 書いてはいけないこと
- 収入・効果の約束（「誰でも月○万円」「必ず伸びる」）。実績は `persona/sales_leads_config.yaml` の `business.achievements` だけ。
- ライバーへの指示・ノルマに聞こえる表現（`eternal-liver-success` の「言い方のルール」）。
- 個人名・売上・順位をライバー全員向けの配信で出す（本人の同意がない限り）。
- 炎上しそうな話題・他事務所や他の配信者を下げる表現（`docs/instagram_team.md` のNGと同じ）。
- 依頼されたPR（他社・案件の紹介）は「PR」を明記（ステマ規制）。

## 6. 送る前のチェックリスト
- [ ] 対象（セグメント）と行動が1つずつ
- [ ] 1行目で誰向け・何の話かがわかる
- [ ] URLが正しく、開ける（スマホで確認）
- [ ] 日付・曜日・価格・締切が設定ファイルや告知と一致
- [ ] 通数が今月の残りに収まる
- [ ] テスト配信（自分や社員だけのセグメント）で見え方を確認
- [ ] 法務に触れそうな表現に `[要法務確認]`（最終判断は専門家）

## 出力の形
1. 対象・行動・配信日時・使う通数（計算式つき）
2. 吹き出し1〜3の本文
3. 1行目の別案2つ
4. チェックリスト（埋めた状態で）
