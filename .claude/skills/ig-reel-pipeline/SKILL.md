# リールを1本作る流れ

メインの Claude が「進行役」になり、Agent ツールで AI社員を順番に呼ぶ（サブエージェントは他の社員を呼べないため）。
**担当どうしの受け渡しはファイルで行う。** 次の担当には「読むファイル」と「書くファイル」を必ず渡す。

## 0. 準備
1. 頼まれた内容からテーマ（無ければ「おまかせ」）と、主に狙う数字（保存数／シェア数／フォロー数のどれか）を決める。指定が無ければ、フォロワーを増やすならフォロー数、問い合わせを増やすなら保存数を狙う。
2. 作業フォルダを作る: `instagram/reels/YYYY-MM-DD_テーマ/`（日本時間の日付）
3. `00_brief.md` に テーマ・狙う数字・頼まれた文面 を書く。
4. CLAUDE.md の「🔒 インスタAI社員の絶対ルール」を全員に守らせる（各依頼文に「絶対ルールを守る」と書く）。

## 1〜5. 担当の順番と受け渡し

| 段階 | 呼ぶ社員（→は順番、＋は同時に呼んでよい） | 読む | 書く |
|---|---|---|---|
| 1 リサーチ | `ig-trend-researcher` ＋ `ig-viral-collector` | 00 | `01_research.md`（各自の節に分けて追記） |
| 2 企画 | `ig-idea-generator`（3案→1案に絞る）→ `ig-structure-designer` → `ig-hook-writer` | 00〜01 | `02_plan.md`（採用ネタ・構成・フック案と採用フック） |
| 3 台本 | `ig-script-writer` → `ig-title-writer` ＋ `ig-caption-writer` | 00〜02 | `03_script.md`（台本・タイトル・キャプション） |
| 4 レビュー | `ig-fact-checker` → `ig-content-reviewer` | 00〜03 | `04_review.md`（確認表とOK／要修正／NG） |
| 5 編集 | `ig-video-editor` → `ig-bgm-selector` ＋ `ig-sfx-designer` ＋ `ig-thumbnail-designer` | 00〜04 | `05_edit.md`（編集指示・BGM・効果音・サムネ指示） |

### 社員に渡す依頼文の型
```
あなたは「リールを1本作る流れ」の〈段階名〉担当です。
読むファイル: instagram/reels/〈フォルダ〉/00_brief.md, …（前の段階まで全部）
書くファイル: instagram/reels/〈フォルダ〉/〈番号_名前〉.md の「## 〈あなたの担当〉」の節
（普段の出力先ではなく、ここに書いてください）
CLAUDE.md の「🔒 インスタAI社員の絶対ルール」を守ること。
最後に、次の担当に伝えたいこと（注意点・未確定の点）を「### 次の担当へ」に3行以内で書く。
```

## 6. 差し戻しのルール（レビューの結果で分ける）
| 判定 | やること |
|---|---|
| OK | 5 編集へ進む |
| 要修正（台本・タイトル・キャプション） | `04_review.md` を渡して `ig-script-writer`（必要ならタイトル・キャプション担当）に直させ、もう一度 4 をやる |
| NG（企画そのものが絶対NGに当たる・根拠が取れない） | 2 企画に戻り、別の案で作り直す |

- 差し戻しは**合計2回まで**。3回目が必要になったら止めて、理由と `04_review.md` をユーザーに見せて判断を聞く。
- 事実確認で「確認不可」の数字は消すか「※イメージです」に変える（推測で埋めない）。

## 7. 仕上げ
- `00_brief.md` の下に「## まとめ」を追記する: 採用フック／尺／狙う数字／差し戻した回数／人がやること（撮影・編集・投稿）。
- ユーザーへの報告は、フォルダのパス・採用フック・台本の要点・レビュー結果・人がやることを短く。全文は貼らない。
- **投稿・編集の実作業は人が行う。** AI社員が作るのは指示書と下書きまで。
- 公開後に数字（保存数・シェア数・フォロー数）が出たら、`ig-data-analyst` → `ig-improvement-advisor` に `instagram/reels/〈フォルダ〉/` を渡して `06_result.md` に振り返りを書かせる（この流れの外。頼まれた時だけ）。
