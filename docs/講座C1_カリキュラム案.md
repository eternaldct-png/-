# AIショート動画 制作＋集客講座（C-1）カリキュラム案

状態：叩き台 第2版（2026-11-28。第1版の「制作だけ」に、集客・受注の部を追加）。
価格・ツール・規約は確認前の案。**販売前に弁護士の確認が必要**（特定商取引法・景品表示法・業務提供誘引販売取引）。税金・請求まわりは税理士に確認する。

---

## 1. この講座で約束すること・しないこと

動画が作れても、お客さんに見つけてもらい、選ばれなければ収入にはならない。そこで、**「作れる」に加えて「自分でお客さんを探して、提案できる」まで**を教える。ただし、結果（収入・受注件数）は約束しない。約束するのは「やり方と、実際にやった行動」まで。

| 約束する（B地点） | 約束しない |
|---|---|
| 15〜30秒のショート動画を1本2時間以内に作れる／作品5本 | 収入・月〇万円 |
| 「誰の動画を作るか」が決まっていて、料金表・プロフィール・問い合わせ先がそろっている | 受注件数・お客さんがつくこと |
| 自分の発信（リール30本の計画と、そのうち10本以上の投稿）を始めている | お仕事の紹介・あっせん |
| 見込み客に提案を10件送った経験と、提案文・見積もりのひな形がある | 「誰でも」「必ず」「〇か月で」 |

**A地点（対象者）**：スマホで写真や動画を撮るくらいしかしたことがない、主婦・会社員・副業を始めたい20〜50代。週4〜5時間を使える人。

**受講に向かない人（販売ページに書く）**：すぐに収入がほしい人／週4時間を取れない人／自分から発信・提案をしたくない人。

| 項目 | 案 |

| 修了条件 | 作品5本、受注の準備一式、リール10本以上の投稿、提案10件 |

## 3. カリキュラム

### 第1部 作れるようになる（5回）

| 回 | テーマ | 授業でやること | 課題 |
|---|---|---|---|
| 1 | 全体像と、使ってよい素材のルール | 制作の流れ（企画→台本→素材→編集→書き出し）。商用利用・著作権・肖像権・BGMの権利 | 作品1：自己紹介動画（15秒） |
| 2 | 台本とカット割り | 冒頭8秒の作り方（`instagram/台本の型.md` の型B）、1秒8文字のセリフ、`/video-brief` で秒割り台本 | 作品2の台本 |
| 3 | AIで素材を作る | 画像生成・動画生成・ナレーション、指示文（プロンプト）の書き方、権利の確認 | 作品2：告知動画（15〜30秒） |
| 4 | 編集と書き出し | テロップのタイミング、止まらない画、音量、1080×1920・30fps、投稿前チェック | 作品3：商品・お店の紹介動画（30秒） |
| 5 | 作品をそろえる | 講評をもとに作り直し | 作品4：解説動画／作品5：自由課題 |

### 第2部 お客さんを見つけて、選ばれる（4回）

| 回 | テーマ | 授業でやること | 課題 |
|---|---|---|---|
| 6 | 誰の動画を作るか決める | 「誰を（A地点）どこまで（B地点）」で自分の売り場を決める（例：美容サロン・飲食店・教室・ライバー・士業）。その業種がSNSで困っていることのリサーチ（`instagram/参考資料まとめ` のリサーチ方法）。料金表・メニューを決める | 売り場の決定シート、料金表 |
| 7 | 受け皿を作る | Instagramのプロフィール（1行目に何者か・2行目に実績）、ポートフォリオページ、問い合わせ先を1つに絞る（フォームかLINE）。「お問い合わせはDMで」にしない | プロフィール、ポートフォリオ、問い合わせ先 |
| 8 | 発信で見つけてもらう | 決めた業種向けのリールを作る（型A〜C・冒頭8秒）、ジャンルを絞る、30本の投稿計画、ストーリーズの使い方、作った動画を「事例」として見せる方法 | リール30本の計画、うち10本以上を投稿 |
| 9 | 自分から提案して受注する | 知人・紹介、地域のお店への提案、スキル販売サイト（ココナラ等）・クラウドソーシングの使い方。提案文・見積もり・修正回数・納期・契約（著作権の扱い）・請求の基本。**営業のマナーと各サービスの規約**（同じ文面の大量送信・自動送信はしない、断られたら追わない） | 提案10件、提案文・見積もりのひな形 |
| 最終発表 | 結果の発表 | 作品・投稿・提案の数、反応、うまくいったこと／いかなかったことを発表し、次の30日の行動計画を立てる | 次の30日の計画 |

- 作品の題材は、自分・家族・知人（本人の許可あり）か、講座が用意する架空の依頼。実在する他人の商品・人物を無断で使わない。
- 第9回の営業は、受講生がスパム扱い・アカウント停止にならないことを最優先にする。InstagramやXで知らない相手に同じ文面を大量に送る方法は教えない。

## 4. 講師側の前提（この講座を売る前に必要なこと）

| 必要なこと | 理由 |
|---|---|
| **ETERNAL d.c.t 自身が、この手順で動画制作の受注を取った実績**（件数・業種・かかった期間） | 集客を教える講座で、講師の集客実績がないと信頼されない。実績のない集客ノウハウを売るのは、景品表示法・消費者トラブルの面でも危ない |
| 自社のInstagram（またはThreads）で、決めた業種向けの発信を先に30本続ける | 第8回の教材と事例になる |
| 試験運用の受講生の結果（行動の数・反応） | 本番の販売ページで使える事実になる |

## 5. 使うツール（候補・すべて要確認）

| 用途 | 候補 | 確認すること |
|---|---|---|
| 台本・指示書 | 自社の `/video-brief`、Claude などの生成AI | 受講生に開放するか（ログイン・費用） |
| 画像・動画生成 | Higgsfield など | 有料プランの必要性、商用利用の条件、生成物の権利 |
| 編集 | 商用利用が認められている編集ソフト | CapCutは商用利用の条件に注意。採用しない前提で比較 |
| デザイン | Canva など | プランごとの商用利用の範囲 |
| BGM・効果音 | 商用利用可の素材サイト | クレジット表記、SNSでの利用可否 |
| ポートフォリオ・問い合わせ | 無料のページ作成サービス、Googleフォーム、公式LINE | 費用、特定商取引法の表示が必要になるか |
| 受注の場 | ココナラ、クラウドソーシング | 手数料、禁止事項（サービス外での直接取引など） |

## 6. 販売ページで使う言葉・使わない言葉

| 使う | 使わない |
|---|---|
| 「10週間で作品5本と、お客さんに提案するまでの準備」 | 「月〇万円」「稼げる」「誰でも」「必ず」 |
| 「提案10件を送るところまで一緒にやります」 | 「受注できます」「お仕事を紹介します」 |
| 受講生の行動と事実（作品数・投稿数・提案数・受注の有無を含む全員分の結果） | 一部の成功例だけを代表例のように見せること、収入の報告 |
| 定員10人（実際の定員） | 実際と違う「残りわずか」「予告なく終了」 |

**販売ページに必ず載せるもの（特定商取引法の通信販売の表示）**：事業者名・住所・電話・代表者、価格（税込）、支払い方法と時期、提供の時期、返品・解約の条件。内容は弁護士に確認する。

**販売の流れ**：販売ページ → 申込フォーム → 決済。Zoomでの個別セールスはしない。質問はDiscordかLINEで文字で受ける。

## 7. 社内のお仕事との関係

- 講座の中で「事務所からお仕事を回す」と言わない・書かない（業務提供誘引販売取引に当たるおそれ）。
- 卒業生にライバーの動画を頼む場合は、講座の販売とは切り離し、別の業務委託契約で、作品と実力を見てから依頼する。進め方は弁護士に確認する。
