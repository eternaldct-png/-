# インスタ台本の書き方

## 1. 書く前に必ず読む
1. `見本/伸びた台本.md` を全部読む。
   - 本文がまだ空（「ここに台本本文」のまま）なら、**そのことを最初に伝え**、下の「基本の型」で書く。
2. 見本から次の3つを書き出してから書き始める（メモは成果物の先頭に残す）。

| まねる点 | 見るところ |
|---|---|
| 話し方 | 一人称・語尾（です/だ）・口ぐせ・呼びかけ方・漢字とひらがなの割合 |
| 長さ | 全体の秒数・文字数、1文の長さ、1カットの秒数 |
| 流れ | フック → 何秒で本題 → 例の出し方 → 締め・CTA の順番と配分 |

## 2. 基本の型（見本が無い時・見本と矛盾しない範囲で）
| 秒 | 役割 |
|---|---|
| 0〜3 | フック（止める一言。内容とズレない） |
| 3〜10 | 悩み・問題（中小企業・個人事業主の「あるある」） |
| 10〜〇 | 解決（手順は3つまで） |
| 終盤 | 証拠（`business.achievements` の事実だけ） |
| 最後 | CTA（保存 or フォロー or 無料相談、1本に1つ） |

- セリフは **1秒8文字以内**。テロップは1枚16文字まで。

## 3. 出す形
```
## まねた点（見本から）
- 話し方: … / 長さ: … / 流れ: …

## 台本（合計 〇秒）
| 秒 | セリフ | テロップ | 画面 |
|---|---|---|---|

## この台本で狙う数字
- 保存数 / シェア数 / フォロー数 のどれを主に狙うか と その理由
```

## 4. 出す前のセルフチェック（1つでも×なら直す）
- [ ] 見本の話し方・長さ・流れに近いか（長さは見本の±20%以内）
- [ ] CLAUDE.md の「絶対NG」（炎上しそうなネタ・人の悪口・根拠のない数字）に当たらないか
- [ ] 数字には出典がある、または「※イメージです」と書いてある
- [ ] 実績は `business.achievements` の事実だけか
- [ ] 1秒8文字以内か（文字数はコードで数える）
