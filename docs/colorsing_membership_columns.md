# ColorSing 月次タブへメンバーシップ関連列を追加する

ライバー管理スプレッドシート
（[ETERNALdct_ライバー管理_運用開始版](https://docs.google.com/spreadsheets/d/1jaBZnxMgy6H8lpOESBWM21hGnswH0NXG3SwBOuRyTu8/edit)）
の **ColorSing 月次タブ** に、`歌推し人数` の右へ次の 6 列を追加します。

1. フォロワー人数
2. メンバーシップ加入人数
3. メンバーシップ新規追加人数
4. メンバーシップ1ヶ月
5. メンバーシップ3ヶ月
6. メンバーシップ6ヶ月

## 対象タブ（9 枚）

`ColorSing_` で始まる月次タブのみ。

- `ColorSing_2025-11` / `ColorSing_2025-12`
- `ColorSing_2026-02` / `ColorSing_2026-03`
- `ColorSing_2026-04` / `ColorSing_2026-05`
- `ColorSing_2026-6-30` / `ColorSing_2026-07-13` / `ColorSing_2026-07-21`

> 入力用ゾーンの **`貼付_ColorSing進捗`** は対象外です。毎月ここへ
> データを貼り付けるため、列を足すと貼り付け位置がずれる恐れがあります。
> 含めたい場合は `scripts/add_colorsing_membership_columns.gs` の
> `TARGET_PREFIX` 判定を調整してください。

## なぜ Apps Script なのか

- 同じスプレッドシート（同 URL）のまま編集でき、別コピーを作りません。
- `insertColumnsAfter` を使うので、既存の数式・書式・
  `INDIRECT` 参照（`担当_*` タブが読む C 列など）を壊しません。
  追加位置は M 列より右なので、C 列参照には影響しません。
- 見出し行がタブごとに 3 行目 / 5 行目と混在していても、各タブで
  `歌推し人数` を検索して見出し行・列を自動判定します。
- 冪等（べきとう）です。すでに `フォロワー人数` がある見出し行は
  スキップするので、何度実行しても二重追加になりません。

## 実行手順

1. 対象スプレッドシートを開く
2. **拡張機能 → Apps Script**
3. `scripts/add_colorsing_membership_columns.gs` の中身を貼り付けて保存
4. 関数 **`addMembershipColumns`** を選択して「実行」
   （初回のみ権限承認ダイアログが出るので許可）
5. 実行ログ、または完了ダイアログで結果（各タブ OK / SKIP）を確認

## 実行後の並び

各対象タブの見出しは次の並びになります（`歌推し人数` の直後に 6 列挿入）。

```
… 枠内月間推しpt | 歌推し人数 | フォロワー人数 | メンバーシップ加入人数 |
メンバーシップ新規追加人数 | メンバーシップ1ヶ月 | メンバーシップ3ヶ月 |
メンバーシップ6ヶ月 | パートナー支払い額 | 進捗 | 登録者数 | 稼働率
```
