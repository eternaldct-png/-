# マンガ要素 画像生成プロンプト集（ChatGPT用）

ホームページ・SNSにマンガの要素を入れるための、ChatGPT（画像生成）向けプロンプト集。
**キャラクター画像を添付して使う前提**。漫画の読みやすさの原則をルールとして各プロンプトに組み込み済み。

---

## 使い方（共通）

1. ChatGPTに **キャラ画像を添付** する
2. 下のプロンプトを貼る
3. 吹き出しは空で生成 → セリフは後から Canva 等で載せる

> 💡 添付画像がある時は、必ず先頭で「**この添付キャラの顔・髪・服をそのまま使って**」と指定すると一貫性が出る。

---

## 画像生成で漫画を作るときの3大注意

| 落とし穴 | 対策 |
|---|---|
| 日本語のセリフが崩れる | 吹き出しは空で生成 → セリフは後からCanva等で載せる |
| コマを詰め込みすぎて読めない | 1枚に入れるコマは最大4つ。見せ場は大ゴマ1つに絞る |
| 視線の流れが崩れる | 日本の漫画は右上→左下。プロンプトで読む順を明示する |

---

## 漫画の「読みやすさ原則」（各プロンプトに組み込み済み）

1. **視線誘導**：読む順は右上→左下。重要な要素ほど右上・大きく。
2. **メリハリ**：見せ場は大ゴマ1つに集中。他は小さく。
3. **吹き出し**：セリフは短く（1個20文字以内）。感情で形を変える（丸＝通常／トゲトゲ＝叫び／雲形・点線＝心の声）。
4. **表情は誇張**：喜怒哀楽をオーバーに。目と眉で感情を伝える。
5. **余白を残す**：背景を描き込みすぎない。感情シーンは効果線で背景省略。
6. **線の強弱**：手前は太線、奥は細線。主役の輪郭を一番太く。
7. **オノマトペ（描き文字）**で臨場感（例：ドン、キラッ、ザワ…）。
8. **1コマ＝1メッセージ**。情報を詰め込まない。

## ① ホームページのヒーロー画像（1枚絵）

```
添付したキャラクターを主役に、Webサイトのトップ用マンガイラストを1枚作って。

【絵柄】日本の少年漫画風。太くて綺麗な線、スクリーントーンの陰影、白黒＋アクセント1色。
【キャラ】添付画像の顔・髪型・服をそのまま再現。表情は自信に満ちて前向き、目にキラッと光。
【構図】ローアングルで迫力を出す。主役は右上に大きく配置し、右上→左下へ流れるスピード線で視線を誘導。
【余白】左上は文字を載せるので何も描かず空けておく。背景は描き込みすぎず、効果線中心でシンプルに。
【線】手前は太線・奥は細線。主役の輪郭を一番太く。
【吹き出し】文字は入れない（空のまま）。効果音「ドン」だけデザインとして入れてOK。
【サイズ】横長16:9。
```

## ② SNS用 4コマ漫画（縦長）

```
添付キャラを主役に、SNS用の縦4コマ漫画を作って。上から下へ読む構成、9:16の縦長。

【絵柄】日本のマンガ風、綺麗な線、スクリーントーン。全コマで添付キャラの見た目を統一。
【1コマ目（状況）】○○（例：真っ白な画面を前に疲れている）
【2コマ目（展開）】○○（例：ハッとひらめいて目が輝く）
【3コマ目（見せ場・大ゴマ）】○○（例：興奮した顔のアップ、周りに集中線）※ここだけ一番大きく
【4コマ目（オチ）】○○（例：満足げに投稿してニッコリ）

【ルール】3コマ目を一番大きく、他は小さめにしてメリハリを付ける。
表情はオーバーに。吹き出しは全部空（文字なし）。効果音は1コマに1つまで。
コマの境目は白い余白でハッキリ区切る。
```

> `○○` を埋めるだけで使える。**3コマ目を大ゴマ**にするのが4コマの黄金リズム。

## ③ SNS用 1コマ（告知・宣伝）

```
添付キャラを使って、Instagram/X投稿用の1コマ漫画を作って。正方形1:1。

【絵柄】マンガ風、太い輪郭、スクリーントーン、目立たせたい部分だけ明るいアクセント色。
【シーン】○○（例：商品を嬉しそうに紹介して指をさしている）
【構図】紹介する物を右上に一番大きく。キャラはオーバーに喜んだ表情。
その物に向かって集中線、キラキラ効果を足す。
【吹き出し】空のまま。下の方は文字を載せるのでシンプルに。
```

## ④ キャラ設定を固める（最初に1回）

```
添付画像のキャラクターを、マンガのキャラ設定シートにして。

正面・上半身、親しみやすい表情。マンガ風の綺麗な線とスクリーントーン。
今後も同じキャラで描けるよう、髪型・輪郭・服の特徴をハッキリ分かりやすく。
背景は白、文字なし。
```

> これで作った画像を保存 → 以降①〜③に **毎回添付** すると、キャラがブレない。

## ⑤ 崩れたときの追い足し指示（そのまま送る）

```

・コマを詰め込みすぎ。見せ場を1つに絞って他を小さく。
・文字は入れないで、吹き出しは空にして。
```
