# ライバー継続フォロー（ETERNAL版 customer-success）

所属ライバーが「来年も続けたい」と思える状態を保つための、事務所側の段取り。
**スコアは声をかける順番を決める目安**であって、ライバーの評価・報酬・契約の判断には使わない。

## 前提（ETERNAL d.c.t）
- 所属ライバー約50人、契約は1年自動更新。社員は2名なので、全員を毎週見るのは無理 → 優先順をつけて回す。
- ライバーは雇用ではなく個人として活動している（業務委託・マネジメント契約）。
  **指示・命令・ノルマに聞こえる言い方をしない**（下の「言い方のルール」）。
- 枠周り・歌推しの記録は `/waku`（カラーシングのルール）。歌推しの話題を出すときはその計算に合わせる。

## 進め方

### 1. データを用意する
スプレッドシートに、ライバー1人1行で次の列を作り、CSVでダウンロードする（見本: `assets/sample_livers.csv`）。

| 列 | 入れるもの |
|---|---|
| 活動名 | 配信名 |
| 契約更新日 | YYYY-MM-DD |
| 今月配信日数 / 先月配信日数 | 日数 |
| 今月配信時間 / 先月配信時間 | 時間 |
| 今月売上 / 3か月平均売上 | 円・コイン・ダイヤのどれか（全員同じ単位） |
| 最終連絡日 | 事務所とやりとりした最後の日 |
| 面談欠席数 | 直近3か月の欠席回数 |
| 備考 | 自由メモ（スコアには使わない） |

### 2. スコアを出す
```bash
python3 .claude/skills/eternal-liver-success/scripts/liver_health.py ライバー一覧.csv
python3 .claude/skills/eternal-liver-success/scripts/liver_health.py ライバー一覧.csv --target-days 15 --format json
```

| 項目 | 配点 | 見ているもの |
|---|---|---|
| 活動量 | 40 | 目標日数（既定20日）に対する配信日数30点＋先月からの落ち込み10点 |
| 売上の推移 | 30 | 今月 ÷ 3か月平均（比べる材料がなければ15点） |
| つながり | 30 | 最終連絡からの日数20点（7日以内満点・30日以上0点）＋面談欠席10点 |

| 優先順 | 条件 | 動き方 |
|---|---|---|
| 最優先 | 50点未満 かつ 更新まで60日以内 | 今週中に代表か担当が個別に連絡 |
| 要フォロー | 50点未満、または70点未満で更新まで60日以内 | 2週間以内に声かけ |
| 様子見 | 80点未満、または気になる点あり | 月1の定期連絡でよい |
| 順調 | 80点以上で気になる点なし | 次の挑戦を相談する候補 |

空欄や読めない値は `※` で出る。**推測で埋めずに、担当に確認してから再計算する。**
目標日数や配点は事務所の方針で変えてよい（スクリプト冒頭の数値）。

### 3. 声かけ文・面談の下書きを作る
スコアの結果と備考を読んで、1人ずつ下書きする。送るのは人（LINE・Discord）。

- **最初の一言は用件なし**: 最近の配信の良かった所を1つ、具体的に（日付・曲名・リスナーとのやりとり）。
- **理由を決めつけない**: 「最近減ったね」ではなく「最近どう？生活とか変わった？」。
- **選択肢を渡す**: 面談は通話／チャット、時間は本人が選ぶ。
- **更新前面談（更新60日前〜30日前）**で聞くこと:
  1. この1年で楽しかったこと・しんどかったこと
  2. 次の1年でやりたいこと（歌・イベント・グッズ・オリジナル曲）
  3. 続けにくい事情があるか（本業・家庭・体調・お金）
  4. 事務所にしてほしいこと
- 続けない選択も尊重する。引き止めのために条件をちらつかせない。

### 4. 次の挑戦の提案（順調な人）
「順調」かつ売上が平均以上の人は、本人が興味を持てば次を相談する。押し売りはしない。
- イベント出演・コラボ枠
- グッズ化（`/goods` の仕組みで販売できる）
- オリジナル曲・カバー音源（自社の音楽制作）
- インスタ・Xでの紹介（`ig-*` のAI社員で下書き）

## 言い方のルール
| 言わない | 言いかえ |
|---|---|
| 「今月は○日配信して」 | 「今月はどれくらい配信できそう？」 |
| 「ノルマ」「最低ライン」 | 「目安」「一緒に決めた目標」 |
| 「辞めたら違約金が」 | （言わない。契約の話は書面で、代表から） |
| 「○○さんはもっとやってる」 | （他のライバーと比べない） |

## 法務・労務の注意（専門家に確認すること）
- **フリーランス新法**（2024年11月施行）: 発注者が個人に継続して業務を委託している場合、
  一定期間（6か月以上とされる）の契約を**中途解除・不更新にするときは30日前までの予告**が必要とされる
  （書面・メール等）。ライバーとの契約がこの「業務委託」にあたるかは契約の形で変わるため、
  **契約を終える・更新しない判断をする前に、社労士・弁護士に確認する**（確信度：中）。
  参考: 厚生労働省「フリーランス・事業者間取引適正化等法」資料、公正取引委員会・厚生労働省「特定受託事業者に係る取引の適正化等に関する法律の考え方」
- 配信の日数・時間を事務所が細かく指示すると、雇用（労働者）とみなされるリスクがある（推測を含む。専門家確認）。
- 売上・個人情報を含むCSVはリポジトリに入れない（`.gitignore` に無い場所で扱う）。

## 出力
- 優先順つきの一覧（スクリプトの出力）
- 最優先・要フォローの人の声かけ文の下書き（1人ずつ）
- 更新前面談の質問メモ
- 推測で書いた部分は「推測」と明記する
