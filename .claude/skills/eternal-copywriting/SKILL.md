# 日本語コピーライティング（ETERNAL版 copywriting）

読んだ人が「自分のことだ」と思い、1つの行動（相談予約・応募・購入）をとる文章を書く。
**事実にない実績・数字は書かない**。それがこのスキルのいちばん大事なルール。

## 0. 先に読むもの
| 書くもの | 読むファイル |
|---|---|
| AI導入支援 | `persona/sales_leads_config.yaml` の `business`（サービス内容・価格・無料相談・**言ってよい実績**） |
| オーディション募集 | `docs/audition_form_questions.md`、`src/web_app.py` の `AUDITION_HTML` |
| グッズ | `persona/goods_config.yaml` |
| 動画制作 | `persona/motion_config.yaml` |
| インスタ連動 | `docs/instagram_team.md`（NG企画のルールはLPにも適用） |

足りない情報だけ質問する（目的のページ・ねらう1つの行動・誰に向けるか・流入元）。

## 1. まず状況を判定する（1行で書いてから始める）
| 判定 | もらったもの | やること |
|---|---|---|
| A. ゼロ／ありきたり | 一言の依頼、どこにでもある会社っぽい文章 | 事実と商品情報から組み立てる。切り口は自由、事実は増やさない |
| B. 本人の声がある | 代表が書いた下書き（荒くても主張や口ぐせがある） | **その声を活かす**。言葉づかい・主張は残し、埋もれた結論・あいまいな所だけ直す |
| C. 部分修正 | 「この見出しだけ」 | 頼まれた所だけ直す。ほかは触らない |

例：「B：代表の下書き。"正直、" "ぶっちゃけ" の口調で、外注より自走を推している」

## 2. 書き方
- **パーツごとに決める**: 見出し・サブ見出し・ボタン・各セクション・証拠の行。それぞれ2〜3案出して1つに決め、最後に通しで読む。
- **3つの問い**（全行に当てる）:
  1. 読んだ人が場面を思い浮かべられるか（「月末の請求書づくりが30分で終わる」＞「業務効率化」）
  2. 本当かウソか確かめられる主張か（「業界最高水準」は飾り）
  3. 同業他社がそのまま使える文か（使えるならダメ）
  2つ以下しか通らない行は書き直すか、`[要確認: ○○の事実]` を残す。
- **決めゼリフは1ページに1〜2か所**（見出しと、もう1か所）。全部の行で決めにいくとAIっぽくなる。
- **変えた理由を言えない修正は戻す**（特にB・C）。

## 3. 事業ごとの勘どころ
### AI導入支援（中小企業・個人事業主 20〜50代）
- 相手の言葉で書く：「AIを使いたいけど、何から始めればいいかわからない」「ChatGPTを入れたけど誰も使ってない」
- 価格（15万〜60万円）の前に、**何が終わるか**（業務の洗い出し→設定→社内で回る仕組み）を見せる。
- 行動は1つ：30分の無料オンライン相談。予約は `https://eternal-interview-booking.onrender.com/book/kazuto`。
- 実績は `business.achievements` の3つだけ（自社ツールの運用事例）。**顧客の削減時間・売上は書かない**（無いため）。

### オーディション募集（歌が好きな人・副業・主婦 20〜50代）
- 不安を先に消す：顔出し、時間の自由、家族バレ、機材、未経験。
- **収入を約束しない**：「月○万円稼げる」「誰でも稼げる」は書かない。収入例を出すなら実在の事実と条件を併記し、「成果を保証するものではありません」を添える。
- 行動は1つ：`/audition` の応募。

### グッズ・音楽・動画
- グッズ：価格は税込・送料込みで書く（`goods_config.yaml` の金額のまま）。
- 動画（`/motion`）：作例はサンプル表記であることを守る（「※数値はイメージです」）。

## 4. AIっぽさを消す（日本語）
次が出たら書き直す：
- 「〜ではなく、〜です」の対比を何度も使う
- 「〜も、〜も、〜も。」の三連発、体言止めの連続
- 「いかがでしたか」「〜してみてはいかがでしょうか」「〜と言えるでしょう」
- 「革新的」「シームレス」「最適化」「ソリューション」「圧倒的」
- 何にでも「！」、絵文字を各行に
- 冒頭の「現代社会において」「近年、AIの進化は」

## 5. 言えない主張の扱い
頼まれた主張に根拠が無いときは、黙って消さずに書く：
> 「導入企業の9割が満足」→ 使えません（根拠となる調査が無い）。代わりに「自社で投稿文の自動生成ツールを作って運用しています」。
> 使えるようにするには：顧客アンケートの結果（回答数・時期つき）が必要です。

## 6. 法令チェック（最終判断は専門家に確認）
- **景品表示法**：実際より良く見せる表示（優良誤認・有利誤認）、根拠のない「No.1」「最安」、期限のない「今だけ」はNG。
- **ステマ規制**（2023年10月〜）：ライバーやインフルエンサーに頼んだ紹介には「PR」「広告」を明記。
- **特定商取引法**：グッズなど通販ページには事業者名・住所・電話・返品条件などの表示が要る。
- 収入・効果をうたう表現は特に注意。迷ったら弁護士・専門家に確認する前提で `[要法務確認]` を付ける。

## 出力の形
1. 判定（A/B/C）と根拠を1行
2. 本文（見出し → サブ → 本文 → ボタン）
3. 見出しの別案2つ
4. `[要確認]` `[要法務確認]` の一覧と、それを外すのに必要な事実
