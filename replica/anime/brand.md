# ブランド: ツヅリ（Tsuzuri）

切り口（`replica/anime/fixes.md` の 5）: **所属ライバー・推しキャラのショートアニメを、続き物で作りたい人へ。1コマずつ直せて、同じキャラで何話でも続きを綴れる。自分のPCで、無料で。**

ひとことで言うと: **コマを綴って、続きまで。**

これはふるい分けで、権利の調査ではない。

## 2. 配色

元のアプリの色は、この環境から公式サイトを開けず確認できていない（`brand.json` の `colors` は空。分かったら足して sweep をやり直す）。
仮の名前（コマドリ）に合わせた橙から、**江戸紫**（物語・創作・夜の配信の色）と、ロゴだけに使う**金茶**（綴じ糸）に変えた。
キキトメ（藍＋朱）とは別の色にして、2つの自作ツールを見分けやすくした。

## 3. ロゴの依頼文（デザイナー・画像生成AIへ）

- **考え方（1行）:** 3つのコマ（絵コンテのコマ）を、左側の1本の糸で和綴じのように綴じた形。コマを綴って、1本の物語にする。
- **形式:** シンボル＋文字（カタカナ「ツヅリ」のワードマーク）。シンボル単体でアプリアイコン・ファビコンに使える。
- **色:** シンボルは江戸紫 `#6b3a9e` の地に、白いコマと金茶の糸。文字は `#1e1b18`。
- **大きさ:** 16px（ファビコン）でも「3つの四角＋縦の糸」が潰れないこと。1024px のアプリアイコンでも間延びしないこと。
- **書き出すもの:** SVG、アプリアイコン 1024×1024（iOS 用は透明なし）、ファビコン一式、SNS 用の画像 1200×630。
- **やってはいけないこと:** 元のアプリのロゴと同じ形・同じ色の組み合わせ・同じ文字の遊び（同じ文字のくり返し・顔に見立てた文字など）を使わない。
  元のロゴはこの環境から確認できていないので、**決める前に元のロゴと並べて目で確かめること。**
- 仮のシンボルは `tools/anime_studio/static/mark.svg`（上の考え方で作った簡易版）。本番のロゴができたら差し替える。

## 4. 言葉づかい（ボイス）

| 3つの言葉 | 意味 | 意味しないこと |
| --- | --- | --- |
| やさしい | 初めてでも迷わない言葉。専門用語は言いかえる | 甘い・子どもっぽい |
| 短い | 1文で言い切る。理由は1つだけ添える | そっけない・命令口調 |
| 監督の相棒 | 選ぶのは使う人。こちらは案を出して、決めたことを守る | 指図する・勝手に進める |

| する | しない |
| --- | --- |
| 「1本に綴じました。プレーヤーで見て、よければダウンロードしてください」 | 「完成しました！！最高の作品です！」（大げさ・決めつけ） |
| 「うまくいきませんでした: 理由。原因を直して『やり直す』を押してください」 | 「エラーが発生しました（code 500）」（理由も次の手も無い） |
| 「カット」「コマ」「場面」 | 「シーケンス」「アセット」「レンダリングジョブ」 |
| 「お金がかかる設定です。約○円」 | 「クレジットを消費します」（いくらか分からない） |
| 「気になるところは、そのつど直してください」 | 「AIにおまかせください」（使う人の判断を奪う） |

書き直した文言（よく目にするもの）:

| 場所 | 前 | 後 |
| --- | --- | --- |
| 作品一覧の見出し | 作品 | 作品 ＋「コマを綴って、続きまで。」 |
| 作品が無いとき | まだ作品がありません。アイデアを数行書くだけで、脚本・キャラ・絵コンテ・動画まで順番に作ります。 | まだ1本もありません。数行のアイデアから、1コマずつ綴って1本の動画にします。続きも同じキャラで作れます。 |
| 最初のあいさつ | はじめまして。…の順に進めます。各段階で確認してから次へ進みます。 | よろしくお願いします。…の順に、一緒に進めます。1段ずつ見せるので、気になるところはそのつど直してください。 |
| おまかせのとき | おまかせなので、最後まで自動で進めます。 | おまかせなので、書き出しまで通しで進めます。途中で止めて直すこともできます。 |
| 書き出しの完了 | できました（○秒）。下のプレーヤーで確認して、ダウンロードしてください。 | 1本に綴じました（○秒）。プレーヤーで見て、よければダウンロードしてください。 |
| 書き出し前 | 「書き出す」を押すと、全部のカットを1本の動画にします。 | 「書き出す」で、全部のコマを1本に綴じます。 |
| 失敗 | 失敗しました: … 直してから「やり直す」を押してください。 | うまくいきませんでした: … 原因を直して「やり直す」を押してください。 |
| つながらない | アプリにつながりません。…起動しているか確認してください。 | ツヅリにつながりません。起動しているか（ターミナルの画面が開いているか）見てください。 |
| キャラ帳が空 | まだキャラがいません。 | まだキャラがいません。よく出すキャラを入れておくと、次の作品にすぐ呼べます。 |

ボタンの言葉（「作る」「OK・次へ」「書き出す」）は、分かりやすさを優先してそのままにした。
