# リール台本の型（CTAまでの流れ）

参考にしたもの：本人が共有した、インスタ運用ノウハウ系アカウントの台本100本（2026-11-28）。
**中身・言い回しは写さない。抜き出したのは「流れの型」だけ。** 台本の番号は、元の台本集の番号。

---

## 1. 100本に共通する骨組み

ほぼ全部の台本が、次の7つの部品をこの順番で並べている。抜ける部品はあっても、順番が入れ替わることはほとんどない。

| 順番 | 部品 | 役目 | 元の台本の言い方（例） |
|---|---|---|---|
| ① | フック（タイトル） | 「誰の」「何の話か」を1文で言い切って止める | 「〇〇って思ってる人、間違いです」 |
| ② | 心の声の代弁 | 見ている人が思っていることを先に言う | 「〜って思いますよね？」「〜で悩んでますよね🥹」 |
| ③ | 結論を先に一言 | 「結論、〇〇です」で答えを先に出す | ほぼ全部に「結論、」が入っている |
| ④ | 問題の拡大 | そのままだとどうなるかを言う | 「放っておくと〜になって、最後は〜」 |
| ⑤ | 理由（仕組み） | なぜそうなるのかを短く説明する | 「理由は〜だからです」 |
| ⑥ | やり方・たとえ話 | ①②③のステップか、身近なたとえで中身を渡す | 料理・ボクシング・運転免許などのたとえ |
| ⑦ | まとめ＋CTA | 結論を言い直し、次の行動を1つだけ頼む | 「やり方はこのアカウントで全部出してます」 |

- 元のアカウント自身も、この骨組みを「タイトル → 問題提起 → 問題の拡大 → 内容」と説明している（台本33・63・91）。
- 冒頭は「誰に何を言う動画か」を最初の1文で出す。何の分野か分からない煽り（「これやると終わります」だけ、など）はダメ、とも言っている（台本87・98）。

## 3. CTAの型（締め方）

元のアカウントは「CTAは基本いらない」「毎回コメントさせるのはやめよう」と言いつつ（台本13・51・53・70）、実際は**売り込まない、軽い頼み方**で締めている。

| 型 | 言い方 | 狙い | 元の台本 |
|---|---|---|---|
| ① 回遊 | 「やり方はこのアカウントで全部出してます」 | 他の投稿も見てもらう（アカウントに長くいてもらう） | 7・10・20・21・73・79 |
| ② 続きはフォロー | 「続きは次のリールで。フォローして待っててください」 | フォロー | 14・18 |
| ③ 固定リール | 「固定のリールで詳しく話してます」 | 回遊 | 64 |
| ④ プロフィールの無料特典 | 「プロフィールの無料資料・説明会へ」 | リスト集め | 52・93 |
| ⑤ 共感のひと押し | 「当てはまったらいいねで教えて」 | エンゲージ | 40・53 |
| ⑥ 言い切って終わる | 「淡々とやりましょう」で締め、CTAなし | 主張の印象を残す | 5・22・94 |

## 4. このアカウントで使うときの決まり（CLAUDE.md の絶対ルールに合わせる）

元の台本は、口調が強い・人を下げる・裏付けのない数字が多い。**骨組みとフックの型だけ使い、次のように置き換える。**

| 元の台本でよく出るもの | このアカウントでの扱い | 理由 |
|---|---|---|
| 「アホ」「情弱」「雑魚」「キモい」など見ている人を下げる言葉 | 使わない。「〜だと、もったいないです」に変える | 人の悪口NG。歌好きの主婦・副業の人・中小企業が相手なので、責めると離れる（推測） |
| 「ゴミコンサル」「詐欺師」など同業を名指し・ひとまとめに下げる | 使わない。下げる相手は**人ではなく「よくある思い込み」**にする | 悪口NG・炎上NG。他事務所への批判は名誉毀損の心配もある（気になるときは弁護士に確認） |
| 「リーチ10倍」「公式で9割」「5億8000倍」など出典のない数字 | 使わない。数字は自分のインサイトの実数か、`business.achievements` の事実だけ | 根拠のない数字NG |
| 「4億」「4万フォロワー」などの実績 | 自社の事実に置き換える。無ければ実績の部品ごと抜く | 同上 |
| 関西弁のツッコミ | 本人の話し方に合うなら軽く使ってよい。ただし相手を責める言い方にはしない | 声は本人のクローン音声なので、本人の口調に合わせる |

**「共通の敵」の作り方**（元のアカウントの考え方：台本44・48）：敵は人ではなく**古い思い込み**にする。

| ジャンル | 共通の敵（思い込み） |
|---|---|
| 歌配信・ライバー | 「長く配信すれば伸びる」「歌がうまければ人は来る」「毎日やらないとダメ」 |
| AI業務効率化 | 「AIは難しい・高い」「全部AIに任せれば楽になる」「うちの規模には関係ない」 |

## 5. そのまま使えるテンプレート（このアカウント用）

尺は今のリールと同じ**18〜30秒**を目安にする（元のアカウントは、知ってもらう段階は短め・売る段階は長め、と使い分けている：台本37）。
セリフは1秒8文字以内。読み上げ文は CLAUDE.md の「🎙 リールの読み上げ文のコツ」に従う。

### 型1：常識の否定 → 正解3つ（狙い：保存）
| 部品 | 書くこと |
|---|---|
| ① フック | 「〈思い込み〉、実は逆です」 |
| ② 心の声 | 「〈思い込み〉って思って、頑張ってませんか？」 |
| ③ 結論 | 「大事なのは〈本当のポイント〉です」 |
| ⑥ やり方 | 「やることは3つ。①… ②… ③…」 |
| ⑦ CTA | 「他のコツもこのアカウントにまとめています」（回遊） |

例（歌配信）：「長く配信すれば伸びる、実は逆です。」→「大事なのは、初見さんが来た最初の1分です。」→ 3つ → 回遊CTA。

### 型2：NG→かわりにやること（狙い：保存）
| 部品 | 書くこと |
|---|---|
| ① フック | 「〈相手〉がやりがちな、もったいない〈場面〉」 |
| ④ 問題の拡大 | 「これを続けると〈困ること〉」 |
| ⑤ 理由 | 「理由は〈仕組み〉だからです」 |
| ⑥ かわりに | 「かわりに〈やること〉をするだけ」 |
| ⑦ CTA | 「保存して、次の〈場面〉で試してください」 |

例（AI業務効率化）：「AIに『いい感じに書いて』と頼むの、もったいないです。」→「毎回書き直しになって、結局手で書くことに。」→「AIは、渡された情報しか使えないからです。」→「かわりに、相手・目的・文字数の3つを渡すだけ。」

### 型3：裏技 → ひっくり返し（狙い：最後まで見られる）
| 部品 | 書くこと |
|---|---|
| ① フック | 「〈結果〉が一気に変わる裏技」 |
| ③ 結論（ひっくり返し） | 「結論、裏技はありません。かわりに〈地味だけど効くこと〉」 |
| ⑤ 理由 | 「理由は〜」 |
| ⑦ CTA | 「続きは次のリールで。フォローして待っててください」（続きはフォロー） |

### 型4：悩みQ&A（狙い：保存・フォロー）
| 部品 | 書くこと |
|---|---|
| ① フック | 「〈よく聞かれる質問〉？」 |
| ② 心の声 | 「〈迷っていること〉、ありますよね」 |
| ③ 結論 | 「答えは〈一言〉です」 |
| ⑥ やり方 | 「〈状況A〉なら〜、〈状況B〉なら〜」 |
| ⑦ CTA | 「配信の相談は、プロフィールのリンクから」（今のCTA） |

例（ライバー）：「歌配信、何分やるのがいい？」→「答えは、時間より終わり方です。」

### 型5：相談・事例（狙い：シェア）※事実がある時だけ
| 部品 | 書くこと |
|---|---|
| ① フック | 「〈状況〉の人から相談を受けました」 |
| ④ 問題 | 「原因は〈本当の原因〉でした」 |
| ⑥ やり方 | 「やったのは〈対策〉だけ」 |
| ⑦ CTA | 「同じことで悩んでいる人に送ってあげてください」（シェア） |

- 実際にあった相談だけ使う。本人が特定されないように書き、数字は本人の許可がある事実だけにする。

## 6. 書いたあとのチェック（4つ）
- [ ] 最初の1文だけで「誰に・何の話か」が分かるか
- [ ] 「結論、」の一言が10秒以内に出てくるか
- [ ] CTAは1つだけか（保存・フォロー・回遊・相談のどれか）
- [ ] 人を下げる言葉・出典のない数字が入っていないか
